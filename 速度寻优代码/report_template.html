1. 项目定位

依据团队技术路线报告，项目总目标为 min JE = Pe(v, ηΩ)， 以实时电功率 U·I 为反馈，在线优化前飞速度 v 与上下桨转速比 ηΩ，技术主线为 在线优先 · 先单变量后耦合 · 先仿真后联调，分四阶段推进：A 速度 ESC → B 推力比 ESC → C 交替耦合 → D 同步多变量。

本次工作 = 阶段 A 的算法原型 + 速度对象 Harness 基线，即整条研究链路的入口。 报告明确指出"找到速度–功率曲线最低点只是算法入口"，创新性来自动态工况、在线反馈与 双变量耦合；本工作在 V3 中额外验证了最优点跳变场景（超出 M1 明文要求），为"动态工况" 这一核心创新主张提供了预研证据。

3. ESC 算法：原理、信号链与关键设计决策

3.1 信号链与四个速度量

v_hat ──(＋扰动 a·sin ωt)──> v_ref ──(被控对象)──> v ──> 代价 J(v)
  ↑                                                        │
  └────────────(梯度估计：由 J 的响应反推方向)──────────────┘

v_ref = v_hat + a·sin(ωt)              # 扰动注入（感知梯度的唯一探头）
g ≈ 窗口最小二乘回归斜率（63 步 ≈ 半周期，J、v 双边去均值）
v_hat ← clip(v_hat − k·g·dt, 0, 20)    # 梯度下降
  • v* 真实最优——只有环境知道，ESC 永远不可见（问题难点所在）；
  • v_hat ESC 对最优值的估计（图上平滑线）；
  • v_ref 发出的指令 = 估计 + 探测扰动；
  • v 实际达到的速度——功率按它计算，不按指令。

正弦扰动的意义：单点测量不含方向信息，必须主动"动起来做实验"才能测出坡度； 选正弦是因为它均值恒为零（不引入漂移）且能量集中在单一频率 ω——像锁相放大器 一样把坡度信号调制到已知频率上，从噪声与漂移中干净地解调出来。探测与到达 是同一件事，这决定了 ESC 收敛到邻域而非精确点（§7）。

3.2 三版本递进逻辑

V1 验证"盲人会不会下山"；V2 加上"这人有反应延迟"（速度惯性使扰动被衰减、 延迟，v_ref 与 v 出现相位滞后）；V3 再加上"山会搬家、还起雾"（最优点跳变、 测量噪声、反馈延迟）。ESC 因扰动永不停止，跳变后自动发现梯度变向并重新跟踪—— 这正是它优于离线优化器的本质原因。

3.3 关键设计决策：窗口回归取代经典解调

技术路线 §6.1 规定梯度由"高通→同步解调→低通"获得。本实现外层结构与公式 (4) 完全一致（v_ref = v̂ + a·sin ωt，v̂̇ = −k·ĝ），但 ĝ 内部改用半周期窗口最小二乘 回归。调试中发现经典方案在本任务上存在两个系统性缺陷：① 工作点移动时高通 瞬态产生 ∝ v̇ 的解调偏置，持续把估计值往错误方向推（实测产生幅度渐增的极限环）； ② 平坦代价曲线上解调信噪比极低。回归对直流、移动、延迟天然免疫。HP/LP 滤波器 仍保留于架构中（直流监视/梯度平滑），参数偏离（k、LP 截止）连同扫描证据已在 文件头与 README 书面记录。

7. 已知边缘项、理论特性与后续衔接

7.1 如实标注的边缘项

  • 调试曲线 V1 v0=15 入带 103 步（阈值 100）；V2 v0=15 入带 251 步（阈值 150）—— 过冲后回稳所致；在 ω=0.5、a=0.5 固定约束下已接近该结构可行极限， 若需严格达标可提高扰动频率缩短回归窗口；
  • 代理曲线为文献量级代理，非 X8 实测（风险表 8 口径），实机数据到位后 仅需替换两个标定参数。

7.2 收敛到邻域的理论特性（答辩高频问题）

ESC 理论保证收敛到邻域：① 扰动是感知梯度的唯一探头，v 必然在 v*±a 摆动 （正弦周期均值为零，时间平均恰为 v*）；② 梯度估计含噪声使 v_hat 小幅游走。 2% 噪声下把 v_hat 从 6 挪到 6.3 代价仅变化 0.0003（远小于噪声 0.02）， ±0.3 m/s 游走是信息论极限。缩小邻域必然牺牲收敛速度或跳变跟踪能力—— V3 要求跳变后重收敛，就注定扰动必须持续存在。

7.3 后续衔接路径

  • M2 推力比在线 ESC（叶安）：在本库 Environment 协议上加 η_Ω 维度， 复用 ESC 类与演示框架；
  • M3/M4 耦合：窗口回归可扩展为二元回归，无需经典方案的 ω_v≠ω_η 频率分离（可写进报告作为结构优势）；
  • RL（Agent+PID/TD3）对照：以本库 V1–V3 后悔值曲线为 ESC 基线， 同一对象协议下接入；
  • 实机迁移：功率按空速计算（地速/空速混淆为路线图风险项）， 实机需优先空速测量。
