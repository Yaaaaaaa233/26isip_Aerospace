## 问题

载具从四轴八旋翼换为四轴四旋翼（老师要求，重心不在转速比优化）。需要轨 A 一条
MATLAB 降阶链供算法线日常实验（迭代快），与轨 B Simulink 权威模型以 M4' 对拍门绑定。

## 对象

`plane.step`（P2，冻结）骨架复用，仅两处差异：

1. **4 电机单桨**：T_i = T_need/4 各自受 T_ce(V) 封顶（H9 同式）；无上下桨分配、
   无共轴干扰项——相关参数键在本包不存在（M3 静态扫描门保证不复活）；
2. **eta 恒 1**：接口字段保留（`eta_ref_applied` 仍必填、输出仍带回），值强制 1。

其余（H6 俯仰内核、H3 前飞诱导节省、H4 废阻、电池链、输出字段名与因果次序）与
P2 逐位同式；台架/电池标定从冻结的 `models/plane/data/calibration/` 只读加载。
`steady_curve` 提供无风配平稳态 P(v) 解析曲线（M4' 轨 A 侧基线）。
