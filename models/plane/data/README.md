# Plane 数据目录

本目录按数据生命周期分层：

- `raw/`：用户/台架/飞行原始文件，只读保存，不覆盖、不改写数值；
- `processed/`：清洗、时间对齐、单位确认后的数据；
- `calibration/`：由原始数据辨识得到、带适用范围和留出验证记录的参数。

## `raw/功率-升力.xlsx`

来源：用户于 2026-09-02 提供的原始 Excel；本次仅移动位置，未编辑工作簿内容。

初步读取：一个工作表，5 组数值点；表头在当前编码读取下显示为乱码，暂不猜测字段含义。数值列形态疑似“油门/电流/升力”，但必须由数据提供者确认后才能用于校准。

在字段、单位、采样条件、传感器和时间基准确认前，不得把它接入 `plane.config`，不得把它标记为 `calibrated`，也不得据此生成真实节能结论。确认后应复制到 `processed/` 并保留原始文件哈希和清洗记录。
