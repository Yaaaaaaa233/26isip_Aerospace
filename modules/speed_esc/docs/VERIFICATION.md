# 实际验证记录

环境：本机 MATLAB R2022b、Simulink、Reinforcement Learning Toolbox。验证日期：2026-08-31。全部性能结论只针对本工程仿真代理模型。

| MATLAB单元测试 | 14/14通过 | `results/acceptance/unit_tests.csv` |

单元测试涵盖功率曲线、一阶响应、延迟配对、左右梯度方向、预热与激励不足、重复采样、冻结恢复、无效/过期数据、参考边界和限速、参数隔离、确定性、RL对象一致性及日志影子回放。

Python复现仅验证兼容移植；改进后的算法并不要求与旧Python逐点相同。Simulink与MATLAB则必须使用同一套改进逻辑，并在相同预生成噪声下逐点一致。

## 2. 性能不是全部指标通过

推荐的窗口回归法共测试74个场景：**功率指标74/74达标，速度定位指标63/74达标。**

V1/V2覆盖两种曲线、2/10/15 m/s初速；V3分别测试2%相对高斯噪声、0.5 s延迟、组合及隐藏最优点变化。带随机噪声的正式场景用种子11至20，未参与前期窗口选择。

最后20秒的无噪声对象功率用于评价，包含微扰和速度响应代价。功率超额阈值V1/V2为1%、V3为3%；实际速度均值误差阈值V1/V2为0.5 m/s、V3为0.7 m/s。

未达到速度阈值的11个回归场景：

| 曲线 | 场景 | 种子 |
|---|---|---|
| 二次调试 | 仅噪声 | 12、18 |
| 二次调试 | 噪声+延迟 | 12、15、18、19 |
| 二次调试 | 噪声+延迟+最优点变化 | 19、20 |
| 三次代理 | 噪声+延迟 | 12 |
| 三次代理 | 噪声+延迟+最优点变化 | 15、16 |

另有4组经典解调对照，功率指标均达标，其中三次曲线V3的速度误差为1.3041 m/s，未达到0.7 m/s阈值。对照数量不足，不能据此对两种算法作普遍优劣排序。

## 3. 如何解读这个结果

二次调试曲线很平：偏离最优速度1 m/s只增加0.003归一化功率。因此“功率超额低于1%”与“准确识别最优速度”是不同验收问题。当前结果支持在所测代理场景中找到低功率区域，不支持宣称所有工况精准收敛。

固定参考基线与优化器使用相同初速、执行响应、限速和噪声场景。离线最优点仅用于评价，不传给控制器；收敛时刻使用后向12.6秒实际速度均值进入容差并持续5秒后的确认时刻。未确认时保留NaN，且确认不保证后面永不离开容差。

完整结果与固定基线等数值见 [逐场景验收报告](../results/acceptance/report.md) 和 `scenarios.csv`。复现入口为 `run_speed_acceptance`，性能未达标项会警告并保留在报告中，不把“程序能跑”改写成“全部指标通过”。
