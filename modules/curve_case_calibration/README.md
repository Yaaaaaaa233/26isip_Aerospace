## ⚠️ 有效性警示（项目组特别标注，2026-09-03）

本模块的曲线标定与 case 门槛建立在**虚拟代理口径**上，且其算法侧结论继承自
`realistic_constraints_search` 的负结果（真实约束口径下因果策略未能逼近理论
最低功率）。联调期间出现过策略跟踪与估计器的多类问题（详见该模块警示）。
**本模块的三 case 曲线族、参数与门槛不一定对后续工作（M3、统一 Plane 的
P(v_air,η) 联合功率对象、真实数据校准）有效或可复用**；标定锚点参考的是
DJI Mavic Pro 文献曲线，与本项目 X8 机型不同，后续应以 P3 工作包的
`P(v_air,η)` 与台架/实测数据重新标定，不应默认沿用本曲线族。此外，本模块沿用
局部"加号风约定"（u=|v·t̂+w|）；仓库已统一为 `v_air=v_ground-wind`（2026-09-03
接口字典 0.3），接入统一 Environment/Plane 时必须先做 w→−w 约定适配，不得
混用参数与场景。

## 定位与问题

任务7之后速度-功率曲线经多轮修改已偏离参考，按参考图像（DJI Mavic Pro，
Battulwar et al. Eq.1：悬停 103.7 W、谷底 6.3 m/s、P(20)=134.5 W）重新标定，
**保留任务2测量噪声**（相对噪声 σ=0.01，可选脉冲）。三 case：谷底功率 = 悬停
功率的 95% / 90% / 85%（case1/2/3），支持面板下拉选择且**选中即预览**
（三条 case 曲线运行前即可见）。与路线图的对应：P3（功率对象参数来源）的
代理口径示例。

## 对象口径

三次光滑标定曲线 + 任务2式对称涟漪（锚点涟漪补偿：P(0)=1 与谷底=case 精确
成立）；内部归一化单位（悬停=1），面板按 pHover=103.7 W 换算瓦特。执行链
（半径/时延/限幅/开环基线）与 `realistic_constraints_search` 一致。

## 入口

## 验收状态与关键结果

证据：[`docs/evidence/curve_case_calibration/`](../../docs/evidence/curve_case_calibration/)。
锚点精确（P(0)=103.7 W，谷底=case×悬停 @6.3 m/s，1e-9 级）；信息价值保持：
known oracle 三 case 超额 0.17%/0.18%/0.19%，开环 4.92%/5.87%/6.93%
——谷越深开环越亏；任务2噪声保留经统计检验。

## 局限

`realistic_constraints_search` 警示；不支持真实 X8 节能表述（红线3）。
