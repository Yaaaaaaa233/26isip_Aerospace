# 任务3.4：四算法整合横比（sweepcal / rl / purerl / hybrid 同包同口径）

> 第三轮（3.x）整合任务（2026-09-08）。把 3.1/3.2/3.3 的四个主角算法收进同一个包
> `+w34`，在同一对象、同一白名单、同一评价口径下横比，并携带 2026-09-08 的
> **高速截断拟合修复(uCap)**。编号见 [../ROADMAP.md](../ROADMAP.md)。

## 一、四个算法是什么（差异速览）

| 维度 | sweepcal | rl(仿真器预训练) | purerl | hybrid |
|---|---|---|---|---|
| 首飞标定 | 150 步双向扫 3→12 | 同左 | 无 | 同左 |
| 脑中的曲线 | f̂ 每 20 步重拟合(反复学) | Stage A 学一次后冻结(造仿真器) | 无模型 | f̂ 近似冻结(60 步维护+双向接受) |
| 风跟踪 | wind_corr 增量修正(每20步) | 不显式跟踪(策略在线适应) | 分桶基线隐式吸收 | wind_corr(每10步, 更细) |
| 每步动作 | 模型闭式解 | 查策略表 | 查策略表 | 模型闭式解 |
| 在线学的对象 | 模型参数 | 策略(模型预训练→真实微调) | 策略(纯奖励) | 风为主、曲线极少 |

共同点：同一对象物理（空速=地速−风、风不影响运动、转圈、时延、限幅、1% 噪声）、
同一红线（只拿带噪功率+自身指令+死推航向）、同一白名单与 MOE 口径、同一指令就位规则。

## 二、2026-09-08 拟合修复（本任务携带的关键改动）

**问题**：扫频顶 v→12 时顺风侧会产生 u≈13–17 的样本，处于曲线陡升+涟漪区，四次多项式
在该区系统性欠拟合（实测偏差 ≈1），最小二乘拿谷底精度去换高点拟合 → **û* 被整体拖偏**
（seed6 恒定风 +0.69、变风 +0.95），3.3 的 hybrid 在变风下 û* 失控（12.51%）即此主因。

**修法（`+w34/fit_curve_wind.m` 双管齐下）**：
1. **高速截断**：u > swHi+0.5 的样本不参与拟合（谷底辨识只需 [3,12]；风辨识靠速度域
   覆盖与航向几何）；
2. **截断后单遍普通最小二乘**：高点欠拟合区不参与后，谷底/中段的四次式不再被拖偏；
   兜底：截断后保留样本 < max(30, 30%) 时放宽到 u 的 90 分位。期间实验过的谷底加权/
   宽带双系数方案实测更差，已弃用（调参史见 ../模型与算法梳理.md 第7节）。

**效果（终验, 2种子800步）**：û* 偏差大幅下降（seed6 恒定 +0.69/+0.95→+0.07/+0.74 量级）；
**sweepcal 恒定风 1.91%、变风 5.10→3.79%（变风首次优于开环）**；
**hybrid 恒定风 2.10%（û*0.44）保持，变风 12.51→10.13%——变风下"标定污染+恢复慢"的
已知限制仍在（详见 3.3 调参史），hybrid 的适用边界不变：恒定风/无风可用，变风用 sweepcal/rl。

**二阶段修复(2026-09-08晚, 截断拟合的边缘假谷)**: uCap截断解决了û*偏差, 但拟合区
右边缘(≈12)失去高u样本锚定——四次式在稀疏边缘弯出"假谷", argmin被吸到边缘, û*冒高
到12并因飞行自采样而自我确认(复合风B=2.5实测12/12种子中招, 每次停留30-125步)。
修复三件套: (1) `curve_argmin` 可选样本支撑选择——只在"两侧±0.75内都有样本的内点
局部极小"中选支撑最大者(真谷底两侧密样本, 假谷只有单侧), 不传样本集时保持原行为;
(2) 删除半程预热拟合(半程只有单向扫样本, (f,w)不可辨识, 其argmin无意义);
(3) sweepcal/hybrid 探针加"当前曲线支撑谷底±1.5"信赖域(hybrid旧版只在维护被接受
时才重锚û*, 探针无界可走到12——即图示"紫星在12而谷底在6.3"), hybrid维护后无论
接受与否都重锚; rl Stage B 仿真器探索域钳到û*±2.5。
效果: B=2.5复合风12种子û*全部6.1-6.5且零跳变, MOE提升1-2个百分点; B=3.5恒定风与
修复前逐seed一致(不扰动已验证行为); 3.4测试42/42+门槛13/13, 3.3测试37/37+门槛
11/11全绿。右上角子图图例改为两列置于右上角(3.1-3.4同步)。
