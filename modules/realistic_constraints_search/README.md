## ⚠️ 有效性警示（项目组特别标注，2026-09-03）

本模块在联调期间暴露了多类问题（est 估计器在部分工况发散并多次结构性返工、
gtrack 交替计数缺陷、oracle 参照的句柄快照缺陷等，均已修复），最终验收入口
虽然全绿，但**所得方法、参数与结论不一定对后续工作（M3 协同优化、统一 Plane
对象、统一 Harness）有效或可复用**：

1. 在真实约束口径（R=50-150 m、空速物理、风摆真实量级）下，**全部因果在线
   策略未能逼近理论最低功率，甚至不敌开环固定速度基线**（本模块核心负结果：
   开环 5.16% vs 已知风 oracle 0.14%，信息价值约 5 个百分点）；
2. 归因显示主要困难是风-最优值摆幅较任务6平移代理口径（windDxGain=0.12）
   放大约 7-8 倍，且相位由控制自身耦合（ψ'=v/R）；
4. 本模块沿用局部"加号风约定"（u=|v·t̂+w|）；仓库已统一为 `v_air=v_ground-wind`
   （2026-09-03 接口字典 0.3），接入统一 Environment/Plane 时必须先做 w→−w
   约定适配，不得混用参数与场景；
3. 后续工作**不应默认继承**本模块的参数、门槛与结论；引用时必须连同本警示
   与证据边界一起。已知风 oracle 结果证明物理上可逼近理论最优，改进方向
   （相位查表/风感知前馈）尚未实现。

## 定位与问题

对任务6自适应算法库（`adaptive_search`）做四项实际约束下的重评估（用户需求）：
1) 转弯半径 500→50-150 m 物理化（航向角速度 ψ'=v/R，周期 T=2πR/v）；
2) 通信时延 0.1-0.5 s（指令 FIFO，地面站→飞机上行）；
3) 加速度限幅 |dv/dt|≤2 m/s²（消除"瞬移"）；
4) 开环固定速度基线（量化算法相对提升，需求4）。
与路线图的对应：P1（固定半径圆周轨迹）/P2（执行动态与变化率限幅）的代理预研。

## 对象口径

空速物理：u = |v·t̂ + w|，P = J0(u − dx) + dy；地速最优闭式
v*(t) = −q + √(q² + u*² − |w|²)。全策略一致施加就位包装器 settled_q
（τ + |Δv|/aMax 就位规则）。黑箱因果接口与任务6一致（红线1/2）。
