# 验证说明

本文件区分三件事：功能检查、解析参考检查和真正的TD3策略成绩。

- `run_checks(false)`：运行单元测试、RL环境完整回合、TD3网络动作边界，以及20个未见不规则风种子的硬约束检查。
- `run_checks(true)`：在上述基础上执行一回合训练冒烟，只证明训练链路可以运行。
- `evaluate_policies(agentFile,...)`：只有这里传入已训练agent得到的 `td3_agent` 行才属于TD3候选结果。

`scripted` 根据可观测风计算解析速度修正，用于确认环境的风信息和动作方向是有效的。它不经过学习，不能放进报告冒充RL性能。

默认硬验收：

```text
所有速度参考位于[2,15] m/s
决策时刻参考变化不超过0.5 m/s/s
固定时长完成，不允许策略提前结束回合
真实功率仅用于评分，不进入策略观测
```

2026-09-01首次完整运行结果：10/10单元测试通过；适配器、RL完整回合和TD3动作边界通过；一回合训练冒烟成功；20个未见不规则风种子均为零硬约束违规。可观测风解析脚本在19/20个种子中功率不高于固定基准，20种子平均代理功率由480.255 W降至474.229 W。该数值仍是解析脚本，不是TD3成绩。

实际数量保存在 `results/acceptance/report.md` 与 `summary.mat`。策略逐种子结果保存在带场景名称的 `results/policy_evaluation_*.csv`。

TD3的建议验收口径为20个未用于训练的不规则风种子中：零硬约束违规，平均代理功率不高于同一基准模块，并同时报告均值、标准差和最差种子。未满足时应标记为“训练候选未达标”，而不是调换种子或只展示最好案例。

## 简单恒定风TD3候选

使用40回合、每回合60秒的可观测恒定风训练，模型保存为 `results/td3_candidate_constant_20260901_095919.mat`。在种子3001–3020的恒定风测试中：

| 策略 | 20种子平均功率 / W | 估算续航 / h | 硬约束违规 |
|---|---:|---:|---:|
| 固定基准 | 477.825 | 0.3139 | 0 |
| 可观测风解析参考（非RL） | 456.984 | 0.3282 | 0 |
| TD3候选 | 463.379 | 0.3237 | 0 |

TD3相对固定基准降低约3.02%代理功率，但仍未达到解析参考。这只证明简单恒定风环境中的学习有效；是否通过不规则风验收必须查看独立的不规则风结果。

同一恒定风候选未经继续训练，直接测试种子2001–2020的不规则风圆周场景：固定基准为480.255 W，解析参考为474.229 W，TD3为539.790 W；TD3在0/20个种子中优于固定基准。硬边界由门控保证，但性能验收明确未通过。下一步应继续执行 `train_curriculum`，不能通过微调测试种子或只展示恒定风成绩规避该结果。

## 随机二维恒定风候选

进一步使用80回合训练，每个回合的恒定风方向与强度随机。候选保存为 `results/td3_candidate_constant_20260901_100959.mat`。

- 未见随机恒定风种子3001–3020：固定基准472.886 W，解析参考457.029 W，TD3 501.108 W；TD3仅5/20个种子优于基准。
- 未见不规则风种子2001–2020：固定基准480.255 W，解析参考474.229 W，TD3 505.473 W；TD3仅1/20个种子优于基准。
- 所有策略均为零速度边界和变化率违规。

这说明简单固定风成功主要反映学会了单一工况动作；扩大风场分布后，当前训练轮数、观测历史和TD3参数尚不足。失败项保留为后续课程训练的基线。
