## 环境模型（任务4核心改动）

单方向风（沿固定方向 windDirDeg）的风速为带偏置正弦：

- **W(t) = A·sin(ω·t) + B**（m/s，可为负=反向）；
- A/ω/B 在左侧参数栏在线可调（默认 A=2、ω=0.08 rad/s、B=3）；
- 飞机仍以 circlePeriod 匀速盘旋（航向 ψ(t)=2πt/T+风向），风的航向投影使
  功率曲线产生**双周期**时变：
  - dxW(t)=windDxGain·W(t)·cos(ψ)（最优空速偏移）
  - dyW(t)=windDyGain·W(t)·cos(ψ)（功率水平偏移）
- **A=0 且 B=0 严格退化为任务1+2口径**（测试覆盖，向后兼容）；
- 黑箱红线不变：搜索器只见 plant.q(v,tag) 带噪测量，环境真值只在评价日志。

## 面板与算法

- 左侧参数栏新增：**风幅值A / 风角频率ω / 风偏置B**（替代任务3的恒定风速）；
- 控制台（tracker/esc、五种平移场景、崎岖参数、能耗开关、日志栏、导出）
  与飞机模型（双表盘+指标）与任务3一致，零删减；
- 寻优对风速变化的适应沿用任务3的 EA 监测设计（大间距斜率探针 +
  重定位/升级分级）：正弦风与盘旋叠加的偏移仍为周期信号，斜率判据可分辨
  任务1式真跳变；连续缓变由 stencil 重定位跟踪。
