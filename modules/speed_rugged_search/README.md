# 任务2：崎岖多峰曲线上的滤波全局寻优

> 五任务路线（路线全文见仓库 `docs/TASKS_1_5_ROUTE.md`）的任务 2。
> 2026-09-01 ｜ 状态：13/13 单元测试、6/6 性能门槛通过（20种子命中率100%、系统偏置−0.04 m/s）

## 问题设定

在任务1的黑箱协议上引入两个真实因素，**不考虑平移**（曲线静态）：

1. **崎岖多峰结构**：曲线出现多个局部极小，单起点局部搜索会落入离初值
   最近的局部谷（"陷阱"）；
2. **测量噪声**：默认1%相对高斯噪声（可调至5%，可开野值脉冲），
   浅谷深度与噪声同量级，不滤波无法分辨结构与噪声。

对象为**调试二次曲线**基准（与 `+speedesc`/任务书同口径
`J0(v)=1+0.003(v−6)²`）加两个**绕 v=6 的负余弦崎岖项**：

```
J(v) = 1 + 0.003(v−6)² + A1·cos(2π(v−6)/λ1+π) + A2·cos(2π(v−6)/λ2+π)
默认 A1=0.022, λ1=6, A2=0.012, λ2=2
```

**对称设计（无偏移的建模基础）**：崎岖项是绕基准最优6的偶函数，曲线
关于6严格对称——全局最优点**精确落在6**（demo红星可验证），7个局部谷
对称分布（v=0.27/2.04/4.33/6.00/7.67/9.96/11.73），全局谷优势0.040。
对称性使"中心对称滤波+对称窗口顶点拟合"类估计量在统计意义上无偏。

黑箱口径与任务1相同：搜索器只能逐点查询(速度→带噪功率)，不可见曲线、
真值最优、噪声与种子；每查询=1评估步(tEval=1s)；速度瞬时生效。

## 推荐方案 multistart：扫描→滤波→pattern search→对称顶点

| 阶段 | 做法 | 评估成本 |
|---|---|---|
| scan | 均匀扫描61点(步长0.333) | 61步 |
| filter | 中心对称Savitzky-Golay滤波(零相位) | 0步(纯后处理) |
| 选谷 | 滤波轮廓取K=5个间隔≥1.5的谷候选+初速候选 | 0步 |
| refine | 每候选两轮"7点采样→移向最小→收缩"(pattern search) | 2×7×2/候选 |
| polish | 最优谷±0.24内5点对称stencil×12次重复均值，最小二乘抛物线顶点 | 60步 |
| hold | 锁定至预算结束 | 剩余 |

**"找到的最优点无偏移"由四道设计共同保证（每道都有对应实验）**：

1. **滤波零相位**：全部滤波为中心对称奇数窗口（移动平均/高斯/中值/
   SG，见 `+task2/apply_filter.m`），对称输入零偏移——单元测试
   `testFilterSymmetryZeroBias`；
2. **滤波只选谷、不定位置**：滤波argmin有结构性右偏（滤波研究实测
   +0.06~0.31 m/s），方案里它只决定"去哪个谷"；最终位置来自polish
   阶段对**原始重复测量均值**的最小二乘抛物线顶点，窗口±0.24落在真值
   谷的严格对称区内——单元测试 `testStructuralBiasSmall`；
3. **对称曲线设计**：如上，统计意义上估计无偏；
4. **跨种子门槛**：验收以20个种子(11–30)的系统偏置 |mean err|≤0.05
   作为"无偏移"的量化验收——**实测 meanErr=−0.044 m/s、命中率100%**。

## 诚实记录：调试中暴露并修复的三个真问题

1. **任务不适定的参数版**：初版崎岖参数下全局谷与次深谷深度差仅0.011，
   小于选择噪声（2%×谷间基线差），任何算法都"看不出来"——改用长波长
   λ1=6拉开谷间基线差、加大A2至0.012（gap=0.040）；
2. **滤波argmin右偏**：对真值滤波后argmin偏移+0.06~0.31（移动平均最差、
   SG/高斯最优），进精调会带偏——改为"滤波选谷+顶点定位"分层；
3. **窗口偏心的三次项污染**：候选偏0.25时以候选为中心的±0.3窗口把真谷
   挤到边缘，抛物线顶点失效——改为pattern search先重定位（两轮收缩），
   polish窗口再以重定位结果为中心。

2%噪声压力场景（任务1噪声口径）的精度极限如实记录在验收报告：
噪声翻倍使位置分辨率极限从约±0.27升至约±0.46，属信息论性质
（谷深曲率/噪声比决定可分辨性），不粉饰为"始终精确"。

## 与任务1/主线的关系与边界

- 自包含：`+task2` 不依赖 `task1_search`（该目录正由他人修改），搜索器
  与滤波器独立实现；
- 无平移是任务2设定；曲线跳变/漂移在任务1处理、风场在任务3–5；
- 对称崎岖设计是"无偏移"要求的建模选择：若改非对称相位，全局最优会
  漂移、对称估计量不再保证无偏（config 中 φ1 φ2 可调，后果如上）；
- 代理曲线、1%噪声为任务口径；结论边界同任务1 README。
