# 纯奖励强化学习模块：无扫频、无模型、免标定学费（第三轮 3.2）

本地编号：**3.2**（本地文件夹 `speed_esc_matlab/3.2_reward_only_rl`，内部包 `+w32`）。
对象物理与 3.1 完全一致（曲线未知、风未知、空速=地速−风、转圈、时延、限幅），
**核心改变：不做 3.1 的 150 步全速域扫频标定**——控制器只靠"调速度→仪表盘功率→奖励"
在线学出每航向最优地速，省掉标定学费。

## 1. 任务设定（用户口径 2026-09-06）

- 曲线未知 ⇒ u\* 未知；风未知；**全程不做扫频标定**：没有"3→12 m/s 快扫"信息来源，
  唯一信息通道是奖励（功率好/坏）本身；
- 红线1落实：`+w32/ctrl_view.m` 白名单（继承3.1），`optimum0`/曲线/风/噪声真值不下发；
  且 pure_rl 结构上无模型输出字段（不辨识曲线、不估计风，纯策略表——测试核验）。

## 2. pure_rl 算法（`+w32/pure_rl_run.m`，模型无关的表格型策略梯度）

表格型 actor：12 个航向桶，每桶一个平均速度 μ(桶)（"在这个航向飞多快"），直接从
奖励学。四层难点与对策（3.1 v0→v2 迭代教训全部继承并强化）：

| 难点 | 对策 |
|---|---|
| ①谷底奖励二阶量（ΔP≈½f''Δv²≈0.005）+1%噪声 → 单步梯度信噪比~0.1 | **大幅值对偶探索**（±1.2 m/s 起步：信噪比∝ε 推到 >1；探索期功率代价 ≈0.7%/步，σ 退火到 0.5 后收回） |
| ②奖励的航向结构污染梯度 | **分航向桶基线**（每桶 EMA，消掉风的调制结构） |
| ③样本饥饿（每桶只分到 1/N 样本） | **邻域共享高斯核更新**（轮廓平滑先验，等效样本×5 且方向一致；实测 24桶×核3 过度平滑发散，12桶×核1 最优） |
| ④大 ε×大 lr 不稳定 + 执行暂态污染信号 | 符号保持2步（等执行到位）+ 瞬态测量不更新（sUsed>1 只采样不学习）+ 步长限幅 + lr 退火（10→2.5） |

调参实证（诚实记录）：探索幅值是"免标定可学"的关键杠杆——σ=0.3 时单步信噪比 0.1
学不动，σ=1.2 时 >1 可学；核宽与桶数必须匹配（24桶×核3 过度平滑反致发散）。

## 3. 结果（MOE = 纯能耗 Emin/Eactual，2026-09-04 口径）

1200 步、2 种子均值（详见 [`../docs/evidence/reward_only_rl/main_comparison.csv`](../docs/evidence/reward_only_rl/main_comparison.csv)）：

| 风况 | openloop(单一速度点) | sweepcal(需150步标定) | rl(需150步+预训练) | **purerl(免标定)** | known(上限) |
|---|---:|---:|---:|---:|---:|
| 无风 | 0% | 1.97% | 2.99% | **2.08%** | 0% |
| 恒定风 3.5@40° | 6.40% | **1.60%** | 2.16% | **3.63%**（μ轮廓幅值6.3） | 0.11% |
| 变风 composite | 4.72% | 5.07% | **3.21%** | **3.51%** | 0.30% |

**达成用户目标**：免标定的纯奖励 RL 在恒定风与变风下都显著优于"单一速度点"基线
（6.40%→3.63%、4.72%→3.51%），150 步标定学费完全省掉。

3×3 验证表：[`../docs/evidence/reward_only_rl/table_3x3.md`](../docs/evidence/reward_only_rl/table_3x3.md)
（purerl 行 0.980/0.965/0.966）。

## 4. ⚠️ 有效性边界（如实标注）

- 稳态精度仍低于有标定的 sweepcal（恒定风 3.63% vs 1.60%）——这是"无模型学习在
  二阶奖励+1%噪声下"的信息论代价，不是实现缺陷；换来的好处是零标定成本、零模型
  假设、每一步都在持续适应；
- 大幅值探索本身有功率代价（±1.2 m/s → ≈0.7%/步，退火后收回）；
- 曲线为 DJI 文献代理、风参数未实测校准；全部结论为 proxy 等级代理口径，
  不支持真实 X8 节能表述（红线3）；
- 若实飞预算允许，3.1 标定法可作为可选的"加速初始化"开关（本模块按用户要求默认关闭）。
