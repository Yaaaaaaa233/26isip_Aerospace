## 1. 控制量定义（红线1的核心）

| 项 | 定义 | 依据 |
|---|---|---|
| 控制量 | **r = η_Ω = Ω_u/Ω_l**（上桨转速/下桨转速） | 与 Opazo 2022 定义一致；项目任务书表1固定采用"上桨/下桨"方向 |
| 定义域 | r ∈ **[0.75, 1.25]**（仿真试验边界） | 项目任务书表1 |
| 开环基线 | r = 1.0（等转速，PX4 默认分配口径） | Opazo §V.B 默认分配 |
| 真值最优 | r* ≈ **0.89**（基准无干扰档） | Opazo §V.C 飞试：最小总电流在 η_Ω≈0.89 |
| 初始状态 | 实际桨比从 1.0（默认分配）开始 | 任务书 M2 里程碑"0.8/1.0/1.2 初值"口径 |

> 提示词中"r=0.5"的示例指"功率占比"类定义；本字典按项目任务书权威口径固定为
> η_Ω（上/下），"上下桨干扰使 r*≠1（等转速点）"，任务书 M2 里程碑与全部文献锚点
> 均在此坐标系内，无需换算。

## 2. 对象接口（黑箱，红线1/2：三原语与 speed_esc_matlab 完全一致）

| 原语 | 签名 | 语义 |
|---|---|---|
| `plant.q(r,tag)` | 指令桨比 → 带噪总功率 | 一条指令经历：通信时延 FIFO（0–0.5 s）→ 桨比加减速限幅 \|dr/dt\|≤slewMax → 子步均值功率；返回 `P_true·(1+1%相对噪声)` |
| `plant.amendEstimate(r)` | 控制器信念回写 | 仅写评价日志 estimate 列 |
| `plant.count()` | 预算查询 | 评估步预算（duration） |

- 控制器只拿：**带噪总功率 + 自身桨比指令 + 采样时间 + 有效性标志**；经 `w11.ctrl_view` 白名单下发。
- **真值 r\*、γ 干扰场、MT 链参数、噪声水平一律不入控制器**（单测核验）。
- 就位规则（`w11.settled_q`，类比机制原样移植）：s = ceil((latency + \|Δr\|/slewMax)/tEval)，
  先以该指令占位 s−1 步（tag='settle'），第 s 步取测量。占位对 hold 语义保持 'hold'。
- 执行链：tEval=1 s，subSteps=10，时延默认 0.3 s，桨比变化率限幅 slewMax=0.15 r/s
  （电机+ESC 转速通道惯性，类比速度包 2 m/s² 口径）。

## 3. 真值模型（对象侧；模型来源详见 README"模型来源"一节）

**结构（每对共轴桨，定桨距变转速，Opazo Eq.(27)–(35) MT 链）**：
给定总拉力 T_arm 与推力比 η_T：T_u=T·η_T/(1+η_T)，T_l=T/(1+η_T)；v_u=√(T_u/2ρA)；
η_v(η_T)=闭式（Eq.(14)/(30)，η_v(1)=1.78077 与文献精确一致）；v_l=v_u/η_v；
Ω_u=√(T_u/a_T)；Ω_l 由"下桨在上桨下洗中的 BET 截面推力积分"二次式正根（Eq.(25)(26)）；
P_u=k·T_u·v_u+(σcd/8)ρA(Ω_u R)³，P_l=k·T_l·(v_u+γ·v_l)+(σcd/8)ρA(Ω_l R)³（Eq.(34)(35)）。

**等效诱导干扰因子 γ（类比"风"）**：乘在下桨感受到的有效爬升流速与诱导功率上
（γ=1 为基准标定态=全发展尾迹假设）；下桨有效下洗系数 cdw 经标定使链的最优桨比
增量与飞试对齐（标定值 ≈0.023，r(η_T=1.5)=0.89）。

**归一化真值曲线（对象最终口径，控制器不可见）**：
```
P*(r; t) = Plev(γ(t)) · [ S(r − Δr(γ(t))) + rip(r − Δr(γ(t))) ]
S: 三次光滑曲线，锚点 P(1)=1（等转速参考）、P(r0)=case、S'(r0)=0、
   边缘形状比取自 MT 链（左缘 P(0.75) 与右缘 P(1.25) 相对深度）
rip: 双余弦涟漪（定义在 r 空间，谷底补偿，A1=0.006/λ1=0.18, A2=0.0035/λ2=0.06）
r*(t) = r0 + Δr(γ(t))（唯一真值最优，涟漪补偿后精确成立）
Emin(t) = Plev(γ(t))·case
```
- **深度标定（诚实口径）**：纯气动 MT 链的谷底很浅（等转速点仅比最优高 ≈0.15%），
  而项目立项依据是飞试"差速分配节能 4–5%"（含电机/ESC 效率与默认分配损失）。
  故形状与漂移取自 MT 链，**深度经功率变换 κ 标定到 case 族**：
  case ∈ {0.97, 0.95, 0.92}（谷底/等转速功率比），默认 0.95 ↔ 节能 ~5%。
- **漂移映射（取自 MT 链数值）**：γ=1.08 → Δr=+0.0275（r* 上移）；γ=0.90 → −0.037。
  方向：γ↑（下桨下洗惩罚更强）→ 最优推力比上移 → r* 上移（单调，单测核验）。
- 文献性质（如实记录）：Opazo 指出"最优点随桨叶数变、不随总拉力变"——变速行不改 r*，
  只改功率水平（飞前 relieved 项按速度包同款 Hwang 代理 c_fwd(V)：P(6.3)/P(0)=0.913）。

## 4. 干扰场（类比 wind_field 七模板，对象侧真值）

γ(t,ψ) = 1 + drift(t,ψ)，七种模板原样移植（const/sin/square/triangle/turb/composite/sector，
sector 以积分航向为自变量——类比"随航向的姿态/来流不对称"）。幅值单位=γ 无量纲：

| 档位 | 3×3 表列 | 参数 | 效果（MT 链换算） |
|---|---|---|---|
| 无干扰 | 列1 | γ ≡ 1 | r* = 0.89 |
| 恒定干扰 | 列2 | γ ≡ 1.08 | r* = 0.9175，功率水平 +1.2% |
| 漂移干扰 | 列3 | composite：1+0.04·sin(0.08t)+OU(σ=0.015) | r* 慢变 ±0.02 ± 湍动 |

场景（scenario）：static / jumpUp（shiftTime 秒 γ 阶跃 +0.06）/ jumpDown / offset
（纯功率水平上移 dy，r* 不变，考验不误触发）/ ramp（γ 慢漂）。

## 5. 评价口径（与速度包完全一致）

- **MOE = Emin/Eactual**（纯续航能耗，2026-09-04 用户口径）；瞬时能效/可用率降为辅助诊断。
- 能耗超额% = (Eactual−Emin)/Emin×100；测量噪声 1% 相对 + 可选脉冲。
- **3×3 验证表**：行=（悬停 / 前飞固定速度 V=6 / 变速 V=6±2·sin），列=（无干扰 /
  恒定干扰 / 漂移干扰）；行1–2 为 openloop 基线（r=1），行3 为 sweepcal；known 为
  oracle 参考上限；每格 3 种子均值，落盘 `results/`。

## 6. 算法阵容（+w11 包，方法论映射表逐项落实）

| 策略 | 移植自 | 一句话 |
|---|---|---|
| `openloop` | 同名 | 固定 r=1（默认分配基线） |
| `sweepcal` | sweepcal_run | 全比域 [0.75,1.25] 双向扫 150 步联合标定 (f̂, θ̂) + 每 20 步重拟合 + 信赖域探针 |
| `rl` | rl_run | 扫频学世界模型 → 仿真器预训练 60k 步 → 部署+真实奖励微调（表格 actor 12 航向桶） |
| `purerl` | pure_rl_run | 纯奖励 RL：免扫频无模型，大幅值对偶探索 σ=0.07→0.03 + 邻域核更新 |
| `hybrid` | hybrid_run | 标定冻结曲线 + 干扰增量修正（每10步）+ 低频维护（每60步，双向接受）+ 信赖域探针 |
| `interfinfer` | windinfer_run | 已知曲线 oracle 参照：滑窗 NLS 反演干扰场 θ=[a0,a1,b1]（均匀漂移+一阶航向谐波） |
| `est` | est_run | 已知曲线 oracle 参照：3 状态 EKF 跟踪 θ |
| `known` | known_run | 已知 γ 场+曲线 oracle 上限（非因果） |

**控制器模型（类比 (f̂,ŵ)）**：P = f̂(r − δ̂(ψ,t)) + c0，δ̂(ψ,t)=a0+a1·cos ψ+b1·sin ψ；
调度闭式解 r_cmd = r̂* + δ̂(ψ̂,t)；r̂*=argmin f̂（样本支撑谷底选择 + û*/r* 锚定信赖域
±0.08 + 双向扫频 + 删半程拟合，四个 2026-09-08 修复全部移植）。域归一化基
x=(r−1.0)/0.25（与速度包 x=(u−7.5)/4.5 同构，条件数健康）。

## 7. 门槛草案（run_checks ≥10 项，验收后写死数值）

1. 单元测试全绿（≥30 项：MT链/漂移映射/涟漪锚点/七模板/执行链/白名单/因果结构）；
2. 七种干扰模板 × 8 策略冒烟：预算走满、测量有限、|dr/dt|≤slewMax；
3. 红线1白名单：ctrl_view 剔除 r* 锚点/γ 场/MT 参数/噪声真值（结构+行为双重核验）；
4. 真值口径核验：无干扰时 r* 精确=0.89、P*(r*)=case、Emin 恒定列；
5. 漂移映射核验：r*(γ) 单调、γ=1.08 时 r*≈0.9175（±0.005）；
6. 无干扰：openloop(r=1) 超额 ≈ 1/case−1（≈5.3%，开环基线的物理来源）；
7. **无干扰：sweepcal 找回 r* 误差 <0.03 且优于 openloop**；
8. 恒定干扰：sweepcal 超额 <3% 且优于 openloop（r* 偏移被标定+精化找回）；
9. **漂移干扰：sweepcal 优于 openloop（提示词指定必查门槛）**；
10. 恒定+漂移：purerl 与 rl 优于 openloop（免标定阵容有效性）；
11. hybrid 与 sweepcal 的恒定/漂移对照结论如实落盘（适用边界对照，允许负结果）；
12. 三种干扰档 known oracle 超额 <1.0%（信息上界）；
13. 3×3 表落盘 `results/table_3x3.md`。
