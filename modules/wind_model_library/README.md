## ⚠️ 有效性警示（项目组特别标注，2026-09-03）

本模块在联调期间暴露了多类问题（策略跟踪滞后、估计器发散史的继承、多次
返工修复），验收入口虽然全绿，但**所得方法、参数与结论不一定对后续工作
（M3、统一 Plane、统一 Harness）有效或可复用**：

1. 在本模块口径下复现并量化了 `realistic_constraints_search` 的负结果：真实
   量级风摆（±3-4 m/s，最优地速每圈在 2~10 m/s 摆动）下，因果在线策略未能
   逼近理论最低功率，开环基线 5.6% vs known oracle 0.2-0.4%（τ=0 与 τ=0.3
   几乎相同——时延不是瓶颈，风信息缺失才是）；
2. 归因实验显示 task6→task9 的 MOE 下降主因是风→最优值传递量级放大约 7-8 倍
   （task6 平移代理 windDxGain=0.12 → 空速物理 1:1），相位节奏次之（约
   +2.6pp），执行动态可忽略（约 +0.15pp）；
4. 本模块沿用局部"加号风约定"（u=|v·t̂+w|）；仓库已统一为 `v_air=v_ground-wind`
   （2026-09-03 接口字典 0.3），接入统一 Environment/Plane 时必须先做 w→−w
   约定适配，不得混用参数与场景；
3. 后续工作**不应默认继承**本模块的风场参数、缺省档与结论；`composite` 缺省
   档与湍流参数（σ=0.3 m/s、相关时间 5 s）为文献典型值，未经实测校准。改进
   方向（相位查表/风感知前馈，工作包2）**尚未实现**。

## 定位与问题

工作包3（风场模型库）+ 空速-地速语义显式化（用户需求）：
1. 七种可选风场模型，面板下拉**选中即预览**（无需运行）；
2. 空速语义：空速 = 地速 + 风速（矢量和），功率由空速决定 → 空速-功率标定
   曲线不随风移动、地速-功率曲线随风平移、仪表盘显示地速；面板同屏对照
   两种曲线，日志新增评价侧列 airspeed/windX/windY（算法接口未动，红线1/2）；
3. 通信时延下限放宽至 0（τ=0 无时延对照口径，需求口径 0.1-0.5 s 保留）。

## 风场模型库（wind_field.m）

| windKind | 形式 | 对应真实物理 |
|---|---|---|
| `const` | Wx=B, Wy=D | 恒定风基线 |
| `sin` | 双正交正弦（任务4-8原口径） | 缓慢周期性天气变化 |
| `square` | 软边方波（陡度 k 可调） | 风区突变/阵风锋（纯方波不物理） |
| `triangle` | 2/π·asin(sin) | 气压梯度缓慢建立的风 |
| `turb` | Ornstein-Uhlenbeck 湍流 | 大气湍流 |
| `composite` | sin 慢变 + OU 湍流（**缺省推荐**） | 真实风 = 确定性慢变 + 宽带脉动 |
| `sector` | 风随航向 ψ 周期变化 | 地形各向异性；盘旋一圈即采样一遍 |

湍流序列以独立种子流（seed+917）预生成，确定性可复现、可运行前预览。

## 验收状态与关键结果

证据：[`docs/evidence/wind_model_library/`](../../docs/evidence/wind_model_library/)。
单元 18/18、门槛 5/5；空速恒等式（日志空速=|地速矢量+风矢量|，1e-9）；
扇区风下 qnewton 是唯一明显胜过开环的策略（4.65~5.92% vs 4.86~6.70%）——
扇区风与航向锁定，可被梯度跟踪利用，为相位查表方向提供依据。
