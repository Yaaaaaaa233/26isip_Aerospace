## 环境模型（任务5核心改动）

地面坐标系（整体可旋转 windDirDeg）中两个正交方向各有一列正弦风：

- **x向：Wx(t) = A·sin(ω1·t) + B**（任务4口径，默认 A=2、ω1=0.08、B=3）
- **y向：Wy(t) = C·sin(ω2·t) + D**（任务5新增，默认 C=1.5、ω2=0.13、D=1）
- 合成风矢量 V(t)=R(φ)·[Wx;Wy]；飞机以 circlePeriod 盘旋（航向 ψ(t)=2πt/T），
  风的航向投影使功率曲线时变：
  - proj(t)=Vx·cos ψ + Vy·sin ψ
  - dxW=windDxGain·proj（最优空速偏移），dyW=windDyGain·proj（功率水平偏移）
- x/y 两列正弦**不同频**（ω1≠ω2），合成风速与方向双重时变，包络缓慢调制；
- **四个风参数全 0 严格退化为任务1+2口径**（测试覆盖，向后兼容）；
- 黑箱红线不变：搜索器只见 plant.q(v,tag) 带噪测量，环境真值只在评价日志。

## 面板与算法

- 左侧参数栏新增：**风幅值C / 风角频率ω2 / 风偏置D**（与 A/ω1/B 并列）；
- 控制台与飞机模型与任务4一致，零删减；
- 寻优适应机制在任务3设计上新增两项（双风时变更强的实测驱动）：
  1. **升级扫描去趋势**：全局扫描改为奇偶交错两段采样、各段减去段均值——
     顺序扫描横跨半个风周期时，时变能级会把滤波 argmin 倾斜到错误谷
     （实测某种子错谷尾段误差 5.7 m/s）；去趋势后错谷消除（总评估数不变）；
  2. **大幅越限宽幅重定位**：水平越限超过 8 倍阈值（错谷/大跳变特征）时，
     9 点宽域扫描(±4 m/s)直接跳谷，避免 5 点 stencil 每次 0.25 的爬行——
     jumpUp(双风) 恢复从 7/10 提升到 10/10 全部 ≤260 步（半数 ≤67 步）。
