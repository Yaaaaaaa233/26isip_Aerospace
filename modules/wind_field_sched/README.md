# 环境风场研究模块：空速物理调度 × 在线风估计 × 三档信息结构

> 本文件夹按 `26isip_Aerospace/docs/TASKS_1_5_ROUTE.md` §3-5 的**路线交付口径**实现
> 环境风场研究模块（任务3/4/5 的统一公式与交付物）。与此前
> `speed_esc_matlab` 的 wind_circle/sin_wind/ortho_wind 三模块不同：那三个模块
> 的对象侧是"风致功率曲线平移"代理（算法线研究），本模块是**空速物理对象**
> 与路线要求的全部交付项（解析调度/DP验证/最优匀速对照/可行性/在线风估计/
> 敏感性扫描/信息结构对比）。

## 1. 对象与公式（路线口径）

- 运动学：飞机沿半径 R 圆轨迹飞行，被控量 = 地速 v(t)（显示值）；
  空速矢量 `u = v·t̂(t) + w(t)`，`t̂=(cosψ,sinψ)`，`ψ=2πt/T_circle`。
- 功率：`P = P0(|u|)`，P0 为仓库三次文献代理（speed_esc 同源）：
  `P0(x)=1−1.5b·x²+b·x³, x=u/V*, b=2(1−P*)`，**V\*=6.3 m/s, P\*=0.913**。
- 解析最优（路线公式）：`v*(t) = −q + sqrt(q²+V*²−|w|²)`，`q=t̂ᵀw`；
  顺风段地速调低、逆风段调高；可行时 `P(t)≡P*`。
- 可行性：**逐时刻**横向风分量 `|w⊥|≤V*`；全周期条件 `max|w(t)|<V*`。
  不可行航向最优努力 `v=−q`（最小化|u|），`Pmin=P0(|w⊥|)`。

## 2. 交付项与结论（验收 8/8 门槛、15/15 测试）

| 交付项（路线要求） | 实现 | 结论 |
|---|---|---|

## 3. 黑箱红线对齐

- `plant` 对象侧每步只返回带噪功率读数（红线1）；空速换算在对象内完成
  （对象升级位置，红线2）；航向 ψ(t) 为飞机可测状态（罗盘），不算真值泄漏；
- 'known'（已知风）策略直接用真风解析式——它是**信息结构参照**（"若风已知
  能省多少"的标尺），非因果算法，报告与面板均如此标注；
- 'online'/'blind' 严格因果：只见测量功率+自身指令+航向+时间。

## 6. 结论边界

- 代理功率对象（三次文献曲线），**不代表真实 X8 节能**；
- 速度瞬时生效（无执行动态），限速DP为未来加速度限制预留接口；
- 在线估计在中频风区(ω≈0.2–0.35)存在谐振区局限（相位查表结构化估计为下一步）；
- 风参数全 0 即无风退化（v\*≡V\*，P≡P\*）。
