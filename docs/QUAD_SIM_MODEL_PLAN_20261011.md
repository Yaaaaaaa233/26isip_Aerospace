## 0. 文档关系与定位

本文件是仓内执行基线，源自《四旋翼 Simulink 建模调整方案 v1.1》（库外，2026-10-11），
吸收《功率建模档位评估与 L1 升级验收清单》第 7 章四件事（第 1 件=P0、第 2 件=P1、
第 3 件=E1/E5、第 4 件=P1）。数据源：《世界记录四旋翼》工作簿（2026-10-11 裁决口径，
列名修正已执行）、上阶段参考资料（PAW 静推表、ZE12070117A 电芯报告、五篇文献、
商飞-飞控通讯协议）。

**核心定位（最重要一条）**：本仿真不是绝对性能预测，不用于评估"能否超过某纪录值"；
它构成项目 harness——让各算法在同一套物理框架下公平比较。物理支撑的职责是保证
涌现结构真实（U 形功率曲线、风调制、电压 sag、控制代价），使算法排名有意义、可反馈
算法优化、为上机做准备。**绝对数据不背书**；评估指标为内部统一归一化 MOE；
精度以"比较保序"为先，缺口按第 4 节登记。

- 控制现实性清单（P2）：执行器滞后+PWM 保持/分辨率；饱和链（PWM/rpm/T_ce(V)/pitch/
  speed bounds）；时延链（测量 0.2s+算法步+执行保持）；噪声链（电压噪声、P_meas
  走估计器口径）；风扰剧本；环带宽/超调上限。验收=Q1 敏感性套件改造的"时延×饱和×
  噪声"磨损表。

### 4.1 P2 磨损表门槛预注册（2026-10-11，先于数据冻结）

单一事实源：`models/plane_quad/+quad_sim/realism_opt.m`；实现链：`+quad_sim/realism_run.m`
（全零默认=与 trim_run 同序逐位无操作，默认配置零改动）。门槛修改须走勘误登记后重评。

| 门 | 内容 | 门槛（预注册） |
| --- | --- | --- |
| G-R0 | 全部格完成同一趟行程且能量有限（可比性） | 全 PASS |
| G-R1 | 保序：典型整链（TYP）最优速度选择与 REF 一致 | 一致（REF 差距 <2pp 的近平手对报告不判） |
| G-R2 | 磨损（M6 同款）：TYP top-2 赢面磨损 \|Δgap\| | ≤1 pp |
| G-R3 | 真实注入：D2/K1/N1 中档相对 REF 留下逐位指纹 | 必须非零（负向证据） |
| G-R4 | 环带宽/超调：REF 与 TYP 阶跃 5→8 m/s | 就位 ≤20 s、超调 ≤20% 步长 |
| G-R5 | 估计链重标定：\|bias(TYP)−bias(REF)\| | ≤2 pp（绝对偏差 C3/C7 只报告） |
| G-R6 | 确定性：RERUN 与 REF 同会话逐位一致 | 逐位 |

矩阵（Q1 形态：OAT 因子族 + 典型整链角点 + 复跑档）：REF、D1/D2/D5（测量时延
0.1/0.2/0.5 s）、K1/K2（执行器：保持 0.02/0.05 s + 斜率 1500/400 µs/s + 分辨率
1/4 µs）、N1/N2（电压噪声 0.5/1.0% + 估计噪声 1.2/2.4%，T1 语义）、TYP（典型整链
全开）、RERUN。策略=巡航速度 {3..9} m/s；任务=固定航程 200 m 前后悬停 5 s；
风扰剧本=头风 2.5 m/s + 正弦 0.5 m/s + 阵风窗 +1.5 m/s（确定性）；噪声种子
20261011（共同随机数，跨策略/跨格公平）。极端档 D5/K2/N2=敏感性探针，如实报告
不设门（与 Q1 ±5% 合成档同定位）。

**勘误登记（2026-10-11，首评后、重评前；门槛数值全部不动）**：首评把
`meas_delay_s` 施于整帧测量（含姿态/角速率）。0.2 s 陀螺反馈滞后使姿态内环失稳，
D2/D5/TYP 坠毁、负能量（被风倒推）、sat 0.84–0.98，首评 FAIL 6 门——数据原样存档
[`quad_realism_firstfire_*`](evidence/quad_migration/quad_realism_p2/)。该结果与实机
飞控不符：0.2 s 是 GPS 级测量时延（T1 语义的慢测量通道），IMU 姿态/角速率与电压
传感为毫秒级。语义修正：`meas_delay_s` 只施于 GPS 级速度测量（速度外环），
IMU/电压不附加滞后；估计链 `est_delay_s`/`est_noise_pct`（T1）不变。附带发现（首评
数据）：该组声明增益下姿态环时延裕度在 0.1–0.2 s 之间（D1 全帧 0.1 s 尚稳、0.2 s
失稳）——"控制能力上限"的直接涌现测量，供 P3/实机辨识参考。重评按本节原门槛执行。
