## 0. 文档关系与定位

本文件是仓内执行基线，源自《四旋翼 Simulink 建模调整方案 v1.1》（库外，2026-10-11），
吸收《功率建模档位评估与 L1 升级验收清单》第 7 章四件事（第 1 件=P0、第 2 件=P1、
第 3 件=E1/E5、第 4 件=P1）。数据源：《世界记录四旋翼》工作簿（2026-10-11 裁决口径，
列名修正已执行）、上阶段参考资料（PAW 静推表、ZE12070117A 电芯报告、五篇文献、
商飞-飞控通讯协议）。

**核心定位（最重要一条）**：本仿真不是绝对性能预测，不用于评估"能否超过某纪录值"；
它构成项目 harness——让各算法在同一套物理框架下公平比较。物理支撑的职责是保证
涌现结构真实（U 形功率曲线、风调制、电压 sag、控制代价），使算法排名有意义、可反馈
算法优化、为上机做准备。**绝对数据不背书**；评估指标为内部统一归一化 MOE；
精度以"比较保序"为先，缺口按第 4 节登记。

## 3. 本次落地（P0/P1，2026-10-11）

- `+quad_sim/baseline.m`：三套机型参数包 `'bg'/'b40'/'b42'`（质量/臂长/惯量/转速

  `quad_sim.config(quad_sim.baseline('b40'))`，既有默认配置零改动（Q2 证据可复现）。

  b42 0.754/1.528，bg 0.683/1.396 kg·m²；替换占位 0.35/0.35/0.60）。
- PM-L1 默认：基线参数包 loadFactor 外推系数 = 0（代码路径保留，Q2 Jgain 证据不受影响）。
- `run_quad_baseline_checks.m`：冒烟验收入口（函数+result+硬断言+裕量/抖动记账）。
- 冒烟 PASS 3/3：悬停锚偏差 −0.000%（两遍逐位一致，抖动 0）；U 形涌现
  v*=3.99/5.99/6.00 m/s（bg/b40/b42）；对工作簿汇总偏差 +13.2/+25.2/+27.6%（C7 如实报告）。
  证据：[`docs/evidence/quad_migration/quad_baseline_p0/`](evidence/quad_migration/quad_baseline_p0/)
  （冒烟 CSV/曲线样张/日志 + 坠落事故诊断日志；`results/` 为本地运行输出，不入库）。
- 调试事故（已修复，worklog 详载）：参数包初版漏同步 config 合并前派生字段

  修复=参数包尾部显式同步两个派生字段。

## 4. 验收：涌现门 + 控制现实性

- 涌现门：E1 U 形与 v* 从物理涌现（冒烟已过；正式=定常扫掠 S1–S6 v=2:2:20）；
  E2 风调制形状；E3 sag→推力天花板；E4 控制代价（瞬态耗能/饱和恢复）；
  E5 基准一致性 sanity（悬停锚 ≤3% 内部门；工作簿汇总 ±15% 报告口径，C7）。
- 控制现实性清单（P2）：执行器滞后+PWM 保持/分辨率；饱和链（PWM/rpm/T_ce(V)/pitch/
  speed bounds）；时延链（测量 0.2s+算法步+执行保持）；噪声链（电压噪声、P_meas
  走估计器口径）；风扰剧本；环带宽/超调上限。验收=Q1 敏感性套件改造的"时延×饱和×
  噪声"磨损表。
