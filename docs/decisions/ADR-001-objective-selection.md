# ADR-001：选择项目主任务与优化目标

日期：2026-09-01
状态：**Proposed，待指导教师确认**
决策负责人：项目组；架构归口为周航正

## 一句话说明

建议把项目主任务定成：**无人机固定高度绕圈等待，在不飞出轨迹、不违反安全限制的前提下，在线调整速度并尽量降低平均功率。**这项选择还要请老师确认。

## 背景

仓库同时包含速度寻优、上下桨转速比寻优、圆周/风场代理和残差RL预研。如果不先确定任务类型，“最低功率”“最低总能量”“最大航程”和“最长续航”会被混用，导致目标函数、场景时长、速度下界和评价结论互不兼容。

## 三种容易混淆的目标

### A. 固定时间盘旋/等待，最小化平均功率

```text
min mean(P_e)
```

优点：直接对应最长留空时间；适合封闭圆周、周期风和不规则风；便于持续在线优化和最终可视化。风险：若没有最低速度和轨迹约束，策略可能通过停住或破坏任务降低功率。

### B. 固定路线/航程，最小化总能量

```text
min integral(P_e dt)
```

优点：任务完成定义清晰。风险：必须明确终点、到达时间和路径约束；与当前平均功率验收口径不同。

### C. 最大航程，最小化单位距离能耗

```text
min P_e / v_ground
```

优点：对应单位电量飞得最远。风险：低速附近数值敏感，且不是当前两周开发主线。

## 我们建议选哪一个

建议选择方案A作为最终主任务：

> 固定高度圆周盘旋等待，在规定最低切向地速、轨迹误差、姿态和执行器约束下，通过在线调整速度参考，并在后续扩展上下桨转速比，最小化固定评价时域内平均电功率。

直线无风平飞保留为开发基线；固定路线和最大航程作为后续任务模式，不与主目标同时加权优化。

## 理由

1. 与项目“降低悬停/巡航功率、延长续航”的原始动机一致。
2. 圆周运动使固定世界风自然表现为沿程周期变化，能连接正弦解析基线与不规则风研究。
3. 固定时长和封闭轨迹便于成对实验、重复统计和可视化。
4. 允许先用速度单变量形成可信基线，再接 `eta_ref` 和候选RL，不要求一次完成二维学习。

## 后果

- 主MoE采用安全任务完成率、估算续航提升率和未见场景胜出率。
- 必须规定最低切向地速、圆周半径/误差和任务时长，防止“停住省电”。
- 平均功率比较必须使用相同时间窗；完成固定航程的结果另立场景和指标。
- Harness、可视化和文档默认围绕圆周盘旋主任务组织。

## 教师确认清单

- [ ] 主任务是最长续航，而不是最大航程或最短时间到达。
- [ ] 最终展示采用固定高度圆周盘旋，直线作为基线。
- [ ] 第一决策变量为沿轨迹切向地速参考。
- [ ] `eta_ref`作为后续第二变量，不阻塞速度/风场架构。
- [ ] 主评价使用固定时长平均功率，并同时施加最低速度和轨迹约束。

若任一项被否决，应将本文状态改为 `Rejected` 或修订候选方案，再更新问题定义、场景和追溯矩阵。
