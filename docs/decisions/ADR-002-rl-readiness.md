# ADR-002：暂缓正式RL开发并设置准入门槛

日期：2026-09-01
状态：**Accepted**
决策负责人：项目组；架构归口为周航正

## 一句话说明

RL代码保留，但现在不把主要时间花在训练上。先把任务、功率模型、场景、接口和评价做清楚，达到下面的条件后再正式训练。

## 背景

`modules/speed_rl_residual`已经提供TD3残差接口、动作门控、风场/电池/轨迹代理和基本测试。现有证据表明：解析可观测风残差在多数未见代理风种子上有效；TD3候选在恒定风代理中有改善，但迁移到不规则风时仅0-1/20种子胜出固定基线。

同时，当前PX4-X8平台功率面未校准且较平，Wind世界坐标接口、圆周任务口径、MoE/MoP、Harness和M2 `eta`分配器尚未完成。在这些定义变化期间扩大RL训练，会使策略学习目标随对象和评价口径反复变化。

## 决策

正式TD3训练、调参与“RL优于基线”的成果开发暂缓。现有RL模块保留为：

- 可替换慢层参考生成器的接口样例；
- 动作门控、历史观测和环境适配器预研；
- 用于暴露问题定义不足的负基线；
- 架构集成时默认关闭的插件。

近期主线优先完成问题定义、Wind-Plane-Control接口、功率对象/数据来源、场景基线、Harness和M2/M3。

## 什么时候可以重新开始正式训练

只有全部满足以下条件，RL才从“预研”晋级“正式候选策略”：

1. 指导教师确认任务和目标函数，平均功率、总能量或`P/v`不再混用。
2. 至少两类风/轨迹场景导致可辨识的不同最优行为，问题复杂性不能由单一解析或ESC基线完全覆盖。
3. Plane功率对象有可追溯来源，并完成校准/留出验证；训练面不是当前平坦未校准平台面。
4. `WindSample/PlaneState/ControlCommand`接口冻结，观测、动作、周期、缺测和回退语义明确。
5. 固定、解析和ESC基线在同一Harness中可一键运行。
6. 训练、验证和至少20个未见测试风种子固定分离。
7. 奖励与正式MoE/MoP一致，提前终止、停住或违反轨迹不能获得更高收益。
8. 候选策略在未见测试中平均功率不高于强基线，报告均值/标准差/最差值，且零硬约束违规。
9. 风速缺测、功率无效和状态异常时，RL可冻结或回退到非学习基线。

## 现在还可以做哪些RL工作

- 维护R2022b环境接口和自动测试；
- 适配统一WPC数据结构；
- 用固定/随机/脚本策略验证动作和安全边界；
- 保留检查点和现有负结果，避免重复踩坑；
- 设计但不承诺最终的观测、奖励和训练课程。

## 现在不能怎样宣传结果

- “强化学习已经解决不规则风优化”；
- “RL优于ESC或传统控制”；
- “代理训练证明真实飞行节能”；
- “训练reward上升等同于续航提升”；
- “零仿真违规等同于实飞安全”。

## 重新评审

完成架构追溯文档中的Gate A-C以及平台路线M2/M4后，由项目组使用以下证据重新评审：

```text
problem_definition_revision
interface_schema_version
power_model_validation_report
scenario_and_seed_manifest
baseline_acceptance_report
harness_metric_dictionary
```

重新启动RL时，优先采用残差结构：

```text
v_ref = guard(v_base + delta_v_RL)
```

其中 `v_base`由固定、解析或ESC基线给出。第一版RL不直接输出PWM，也不同时承担全局多峰选择、轨迹控制和上下桨分配。
