# 五任务速度优化技术路线（2026-09-01 定稿）

本文件是"速度寻优问题五项建模任务"的总路线。实现按任务分文件夹落在本工程内
（`task1_search/`、后续 `task2_rugged/`、`task3_wind_circle/` 等），每任务独立可运行、
独立验收；`+speedesc/` 包与本目录既有成果不动。

## 0. 公共建模基础

- 符号：`v` = 飞机速度（黑箱可操作/显示的量，m/s）；`V*` = 功率曲线最低点（代理曲线
  6.3 m/s，P*=0.913）；`w` = 风矢量。功率按空速计算；任务 1–2 无风。
- 对象曲线族沿用仓库代理（二次调试 / 三次文献），不重标定气动。任务 1–5 研究的是
  优化算法对扰动/噪声/风场的响应，不是气动建模。
- 黑箱协议：优化器每步只能提交一个速度并收回一个功率读数；不可见曲线形状、真值
  最优、扰动真值；离线最优只用于事后评分。任务 1 起取消执行动态（速度瞬时生效），
  这是算法选型的分水岭。
- 评价口径：功率后悔值（路线图表 7）；另设**搜索能耗口径**——把寻优过程本身烧掉的
  电计入全程平均（续航纪录叙事）。搜索能耗设有开关，可按需启用或关闭。

## 1. 任务 1：曲线平移 + 瞬时跳变黑箱 + 搜索算法选型（`task1_search/`）

- 对象：`P(v,t) = P0(v − Δx(t)) + Δy(t)`，Δx（左右平移）、Δy（上下平移）在未知时刻
  跳变或慢漂。任务 1 无噪声。
- 选型结论：**黄金分割主干 + 抛物线插值加速（Brent 式混合）+ 平移监测重夹逼跟踪器**。
  理由：
  1. 无噪声单峰、无执行动态设定下黄金分割是逐次评估意义最优的确定性搜索
     （每评估一次区间收缩 0.618，[0,20] 达 0.01 m/s 约需 17 次评估）；
  2. 可终止 → 稳态零扰动代价；ESC 收敛到邻域，永久付出约 ½P″(V*)·a² ≈ 0.18% 功率
     超额，对全程平均计分的续航纪录不利；
  3. 平移后再收敛成本极低：锁定后周期性三点复探，检测到斜率越限即以旧最优点为
     种子重新夹逼，十几次评估内完成再收敛；纯上下平移（Δy）因不改变 argmin 被
     天然滤除，不触发重搜。
- 对照基线：网格扫描、三分搜索、纯黄金分割、ESC（连续跟踪代表）。基线为搜索后
  锁定策略（无监测），其在平移后的停滞即跟踪器价值的直接证据。
- 能耗开关：`task1.config('energyAccounting',true/false)`。开=计入并用于评分/验收；
  关=只看定位精度与稳态指标，能耗列记 NaN。

## 2. 任务 2：崎岖多峰 + 噪声 → 滤波后全局寻优（`task2_rugged/`，待做）

- 对象：`P(v) = P0(v) + Σ Ai·sin(2πv/λi + φi) + n(t)`，主谷全局最深，叠加浅局部谷
  与相对噪声（可含脉冲野值）。
- 滤波分工：滑动平均压白噪声但钝化谷底；Savitzky-Golay/高斯核保曲率；中值滤波
  除脉冲；低通 IIR 用于在线。窗口长度与主谷曲率尺度的权衡需量化（偏置-方差）。
- 全局化：滤波后多起点黄金分割（播种-局部收敛-取最优），与模拟退火/贝叶斯优化
  小规模横评；验收以**全局**最优为真值口径。

## 3. 任务 3：恒定单向风 + 圆周运动（`task3_wind_circle/`，待做）

- 运动学：飞机沿半径 R 地速圆轨迹运动，可控量 = 地速大小 v(t)（显示值）；恒风
  `w = W·x̂`；空速矢量 = `v·t̂(t) + w`；瞬时功率 `P = P0(|空速|)`。
- 解析最优（功率只依赖瞬时空速且速度可瞬时调整 → 逐点最优即全局最优）：

  ```
  v*(t) = −(t̂(t)·w) + sqrt( (t̂(t)·w)² + V*² − |w|² )
  ```

  顺风段地速调低、逆风段调高；此时 `P(t) ≡ P_min`。可行性条件 `|w| < V*`。
- 交付：变速最优调度 v*(t) 与 P(t)；最优匀速对照（一维搜索）；DP 数值验证解析解
  的全局最优性（DP 兼作将来加速率限制的接口）；在线版（风估计 + 相位查表）。

## 4. 任务 4：单向正弦变化风（待做）

`w(t) = W0 + Wm·sin(ωw·t + φ)`（方向固定、幅值正弦）。任务 3 公式中 `w → w(t)`
直接成立；v*(t) 为圈频与风频的双频函数。新增内容：可行性条件 `max|w(t)| < V*`；
在线版中风估计滞后代价随 ωw 增大的敏感性扫描与带宽设计准则。

## 5. 任务 5：两正交方向风矢量合成（待做）

`w(t) = (Wx0+Wxm·sin(ωx t+φx), Wy0+Wym·sin(ωy t+φy))`。任务 3/4/5 是同一公式在
w 取常矢量、一维时变、二维时变的三个特例（统一公式见任务 3）。交付：统一风场模块、
解析调度、DP 验证、可行性检查（合成风幅值包络 < V*）、"已知风/在线估计风/不知风"
三档信息结构的后悔值对比（回答风速信息价值几何）。
