## 3 执行方案（分阶段）

### 阶段 0：机械解锁（~0.5 h）

1. `modules/README.md` 登记两模块（purerl_pretrain_split：王健祺；platform_link：王健祺原创/叶安接手修复），状态列如实写"3.5 全绿；3.6 接手修复中"；
2. 本方案文档入库；
3. 治理脚本复跑 PASS（当前因 F7 FAIL，任何提交都被挡）。

### 阶段 1：根因 + 机械修复（~2 h，F1/F4/F5）

1. **F1**：`make_platform_plant.m` 的 `q()` 内 `adv(stepPerSec)` → `adv(1.0)`；删除失去用途的 `stepPerSec` 定义行；
2. **F4**：`make_platform_plant` 构造处加 `rng(c.seed)`（与 `make_plant.m:30` 同语义）；
3. **F5**：三处 `exist(...,'file')~=2` 探测 → `isempty(which(...))`；`repoRoot` 改两级回溯 `fullfile(root,'..','..')`；入口断言改 `~isempty(which('plane.config'))`；
4. 新增单元测试（M1/M5，见 §5.1）；
5. 每项改后跑 20 s 级平台 sweepcal 单策略复现（影子验证脚本口径）核对：calibSteps=150、单次 q() 推进恰 1.000 s。

### 阶段 2：Phase B 守卫（~0.5–1 天，F2/F3）

三道守卫全部落在 `sweepcal_run.m`（+必要处一行钳位），不改三原语接口、不读任何真值列（守卫只用控制器自有的 rnPsi/rnV/ŵ，红线 1 合规）：

1. **守卫 A（风物理界）**：每次 `wSm` 更新后钳位 `wSm=min(max(wSm,-8),8)`——8 m/s 即 `fit_curve_wind.m:52` 已注册的物理上限，与其一致；
2. **守卫 B（覆盖门）**：`wind_corr` 仅在最近窗口信息充分时执行：航向扫角 ≥ `p.wiSweepMin`（0.8 rad，config 已有，借 2.1 语义）**且** 指令速度极差 ≥ 1.0 m/s；否则本轮跳过修正。直接切断 F2 的退化几何反馈回路（趴窝时速度极差≈0）；
3. **守卫 C（兜底指令）**：disc<0 时 `v` 保持上一条可行指令（记忆变量，钳位在 [lower+0.3, upper−0.3]），nDisc 照计（报告用）。守卫 A/B 生效后 nDisc 应自然归零，C 为纵深防御——数学伪影不得把飞机指令打到近悬停。

迭代方式：每改一道守卫跑一次平台 sweepcal 复现（~20 s/跑），监控五元组（终值 û\*、windFinal、nDisc、refine 段平均地速、超额/尾段），直至 M2 的 platSweep/platTail 在 seed 11 过带。

### 阶段 3：正式批 + 证据重出（跑批 ~1–2 h + 文档 0.5 h）

1. 工作树冻结，`run_task36_checks` 全量正式跑（单测含新增、冒烟矩阵、主口径横比、平台五门）；

4. worklog `docs/worklog/2026-09-09-zcode-t36-takeover.md`、状态页第 16 更；
