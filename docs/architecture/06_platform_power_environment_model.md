## 1 定位：并线后的平台线

组织：霍奕茗的 Plane 工作（P0–P4 契约资产，署名保留）并入叶安的平台线；平台线成为 Simulink/仿真侧唯一归口，负责两个模型：

- **动力模型**：转写飞控（算法指令 → 执行）、在分配层面模拟飞机功率（每电机转速/功率 → 合成总功率），含螺旋桨功率、电池电压；
- **环境模型**：模拟风，与算法端使用同一份风（同一真值源驱动，算法侧只见测量面）。

职责边界（平台验收的对象）：正确模拟无人机运动、正确转写飞控、正确模拟风的影响。平台的"指标"不是优化量，而是**保真度误差族**（§8）。

## 2 总体架构

```text
场景设置（半径 R / 风参考 / 种子）
   │
   ▼
环境模型（风）────────────┐
  世界风 w⃗(t)             │ 同一份风真值
  → 切向分量 w_t = w⃗·t̂(φ) ▼
场景包装层 ──▶ 动力模型（直线飞控内核 + 功率合成）
  line  : t̂ 恒定            ① v_ref → 速度跟踪（τ、限幅）→ a_t
  circle: t̂ 随 φ 旋转        ② 俯仰 θ ≈ arctan(a_t/g)（一阶滞后）
  位置簿记: s(t)=∫v dt       ③ T·cosθ = mg（高度保持）
        φ(t)=s/R            ④ 分配器（M2 受约束 PWM 域）→ 8 电机 n_i / PWM_i
                              ⑤ P_i = P_elec(n_i; V_bat, v_air)（台架标定）
                              ⑥ P_total = Σ P_i → 电池电压反馈 → 测量量化
   ▼                                    ▲
测量面（v / P_meas / 位置·相位 / SOC / flags）─ 算法端 policy（v_ref, eta_ref）
   └─▶ 评价器（Percent / MOP-MOE）+ WPC 可视化
```

四条结构决策：

1. **直线飞控内核**：飞控只模拟直线平飞控制（俯仰调速 + 高度保持 + 电机分配）。转向不由模型处理，由金属环**硬性约束**施加；机头沿切向是约束的结果，不是被控量。
2. **line / circle 同一内核两种包装**：`trajectory_type` 不是两套模型。line 风投影恒定（开发基线，解析期望全已知）；circle 切向矢量随相位旋转，固定世界风自然表现为 w_t 的周期调制（w_t ≈ W·cos(vt/R)，ω = v/R；R=100、v≈8 时 ω≈0.08 rad/s，与算法端任务 7 预设 windOmega=0.08 同一量级——算法端正弦风研究与圆周场景是同一物理的两种参数化，应写进场景文档统一口径）。
3. **风的单一入口**：风不进力平衡、无直接动力学作用（不吹跑、无摩擦），唯一作用路径是 w_t → v_air = v − w_t → 每电机功率的前进比修正。世界风的法向分量进入空速矢量恒等式（air = ground − wind）但无动力学/功率后果，**声明式丢弃并登记**。
4. **指令级限幅与物理上限分层**（2026-09-08 叶安拍板）：链条①中的 `speed_rate_mps2 = 2 m/s²` 定位为**飞控指令级参数**——真实飞控的速度/倾斜指令饱和是被转写对象的一部分，显式存在是转写保真度，值随 H6 登记。**切向加速度的物理上限不由运动学另行声明，而由俯仰角限制与推力余量涌现**（θ_max、拉力上限，且随 V_bat 跌落下降）。据此 P2 实现须把分配器**实际输出推力回馈到运动学**：饱和 shortfall 不再只进功率/flags，而是体现为实际加速度低于指令并点亮 rpm/PWM 饱和位；"电池跌落使涌现上限压过指令限幅"即为标准饱和负向测试。接口 §5 的声明值保持**描述性契约**地位（供算法建模），验收增加"声明值 vs 涌现值一致性"对照，不构成第二重执行。
   **饱和位登记（2026-09-08 叶安拍板）**：rpm/PWM 饱和位取平台 flags **bit4**——经协议 docx（`【20260710】商飞-飞控通讯协议_V1.0(4).docx`，创衡 S 系列）逐位核对，其报警状态字 1 的 **bit4 = "转速异常"** 为协议原生语义位，平台 flags 与之对齐可使 P4/P5 真机遥测对接时语义连续；协议 bit1 = "舵机电压低"，不可挪用。语义差异登记：平台 bit4 在仿真中承载"rpm/PWM 饱和/涌现上限触发"，映射到协议报警字"转速异常"报警位。

## 3 建模范围与数据对照

总原则：参考数据标定"可测的部分"（推进系统、电池），文献/模型补"不可测的部分"（前进比、共轴干扰、废阻），几何与守恒律自洽的部分不消耗数据预算。

| 模块 | 建模内容 | 数据状况 | V1 策略 |
|---|---|---|---|
| 运动学（金属环） | s=∫v dt，φ=s/R，切向/法向分解 | 无需数据（几何自洽） | 完整建模；验收 = φ·R≡∫v dt 恒等式 + 相位闭合 |
| 切向执行动态 | 一阶惯性 τ=1 s + 指令级限幅 2 m/s²（飞控参数，见 §2 决策 4）+ 夹断 [0,20] | 无直接数据 | 合理缺省；只影响趋近速度不影响稳态最优点；物理加速度上限由俯仰/推力/电池涌现 |
| 姿态 | 俯仰准静态 + 一阶滞后；倾侧=0；偏航不存在 | 无数据 | 唯一姿态自由度是俯仰；全刚体姿态动力学留 V2（接口不变，只换内部实现） |
| 转向 | 不建模（硬约束） | — | 登记简化：航向旋转 ψ̇=v/R 不产生被计量的偏航力矩/功率，二阶小量 |
| 分配器 | T、θ、eta_ref → 8 电机转速/PWM（共轴对上下差动 = eta） | **已有实现**（M2 受约束 PWM 域分配器，验收过） | 直接复用；整机重量按拍板值 10 kg（§3.1 H1）；电机安装几何缺省（机体图纸可补） |
| 电机+桨+电调 | P_elec(n; V)、拉力-RPM、扭矩-RPM、效率 | **有直接数据**：444 点台架 sweep（18–30 V 多档） | 标定主体；静态特性直接拟合 |
| 前进比修正 | P(n, V, v_air) ≠ 静态值 | **缺**（台架空速=0） | 叶素/BEMT 或文献修正因子缺省，登记不确定性 |
| 共轴干扰 | X8 四对共轴，下桨洗流损失 | **缺**（台架为单桨） | 文献系数（效率×0.85–0.9）缺省；eta 功率效应幅度依赖此系数，须做敏感性 |
| 机体废阻 | P_drag ∝ v_air³，决定 U 形右支与 V* 位置 | **缺** | 文献/CFD 估 CdA + 敏感性分析；**U 形形状最大不确定源** |
| 电池 | V_bat = OCV(SOC) − I·R_int；截止电压→P=0 | **已定**：7S4P（H2，单芯 24 Ah、满充 4.25 V、截止 2.8 V 建议值）；单芯参数取电芯报告；台架表电调电压随电流跌落 | 容量/内阻按 4P 折算后接入；V1 可先恒压+慢漂 |
| 风 | 场景输入（七种风场库复用），只进 v_air | 无需数据（场景参数） | 风测量退化（噪声/延迟/缺测）参数缺省 |
| 测量链 | 量化/延迟/丢帧 | **有参考**：创衡 S 系列协议分辨率（主电压 0.1 V / 电流 1 A / 转速油门） | V1 按协议分辨率+轻噪声，逼近真飞控遥测 |
| 明确不建模 | 全刚体六自由度平动、PWM 开关级细节、阵风对力直接作用、电机/电池温度、桨弹性 | — | 逐条登记"为何可缺 + 何时必须补" |

**U 形曲线是合成的，不是拟合的**：静态台架给左支（诱导+旋转损耗），废阻模型给右支，谷底 V* 主要由 CdA 与重量决定（均无直接数据）→ V1 的 P_nom 必须带不确定性带 + 敏感性分析。与 ADR-004 自洽：名义图不必等于运行对象，偏差是设计的一部分。悬停工作点检查（Σ拉力=mg 反解单桨油门，落在效率曲线良区）只用台架数据即可做，是标定报告第一张图。

**proxy U 形退役与 P_nom 重建口径（2026-09-08 叶安拍板）**：T1 开环阶段的 proxy 功率对象（P_min=900 W 占位量级）自 P2 起退役为**历史对照**，不再参与任何验收门槛与口径；T2 的 P_nom、E_pred、Percent、MOE 全部由冻结后的 P2 合成模型重建——E_pred 沿用 T1 冻结流程（名义图沿计划调度 4-迭代固定点 rollout，含计划暂态，每种子一份、两臂共用分母），重建所用名义图版本在**跑批前随场景预登记入库**（防"看结果调名义图"的循环论证）。数值不跨模型横比：T1/M3 的历史能量数值与裕量不迁移至 T2。

**eta 的物理效果只有在本链中才成立**：共轴对差动加载使两个工作点在效率曲线上挪动 → 总功率变化。这是 M3 复跑（T2.4）的前提；其幅度依赖共轴干扰系数，标定报告须声明不确定性。

2. 拟合 P_elec(n; V)、拉力-RPM、扭矩-RPM、效率族 → `calibration/`，带适用范围；
3. **留出验证**：按电压档/工况分层留出点，报告留出误差；
4. 等级声明：参数来源 proxy → `calibrated`（限台架覆盖域）；前进比/共轴/废阻项标 `literature/model`；
5. 名义图 P_nom(v_air) 重拟合并版本化（算法端拿冻结版本，符合 ADR-004 信息边界）。

**电芯报告人工核对点（2026-09-08 叶安拍板，硬规则）**：`1_电芯测试报告f(3).pdf` 为非结构化 PDF，其中任何取数在进入清洗/拟合/入库之前，必须**暂停任务并向文件负责人展示"取数单"**：出处（页码/表名）、原始数值、解读含义、拟代入的模型参数（如 OCV(SOC) 曲线、内阻、满充/截止电压、容量、倍率限制）与用途、以及报告中缺失或不明确处的清单，经确认后方可使用。电芯参数直接决定电池模型与电压反馈链，是仿真可信度的关键步骤，不得由 agent 单方解读入库。台架 xlsx 与协议 docx 为结构化文件，按常规清洗流程处理；发现歧义同样先沟通再动。
