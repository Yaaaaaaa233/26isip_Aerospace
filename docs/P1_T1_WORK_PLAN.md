## 1 定位

P1 = 平台线在 T1 窗口（9/8–9/11）的全部工作。两条线并行：

- **主线（T1 验收）**：把已验收绿的 proxy 级 `plane.step` 经 P4 适配器接入统一 harness，替换 aircraft 代理，通过开环验收；
- **副线（P2 前置 + 债务）**：台架数据清洗与标定 v0、验收图集脚本 v1、M3 F4 验证器修复。

被测平台是现有 proxy 等级对象，**不是**新写的物理链（飞控内核/分配器/每电机功率/电池模型均为 P2 内容）。

## 5 风险

1. harness/ENV 就绪时间滑动 → WP2/WP3 顺延，WP4/WP5 脚本部分不受阻；
2. nominal_sched |Percent| 超 5% 参考带 → 归因分析（执行动态/名义图偏差/电池），不自动 FAIL；
3. M3 F4 修复超期 → 不阻塞 T1 主线，T2.4 前收口即可；
4. R2022b 堆崩溃 → 分段驱动模式（OPEN LIMITATION 惯例）。
