## 1 定位

P2 = 平台线在 T2 窗口（9/12–9/18）的全部工作：把 T1 验收过的 proxy 功率/电池对象**升级为物理化链条**，接口签名与字段不变（只换对象内部实现）。P2 完成前 P1 已关闭（T1 验收 21/21 + B2 人工核对，2026-09-08）；M3 §7.3 正式批次复验已 PASS（修复方自验），T2.4（M3 统一 Plane 复跑）以 M3 独立复验 + P2 验收双前置。

P2 建成后被测对象变化一句话：`power_w` 从 proxy U 形变为**分配合成的总功率**（每电机台架拟合），`voltage_v/soc` 从窗口占位参数变为 **battery_model_v1 物理链**，速度跟踪从一阶惯性变为**俯仰飞控内核**，加速度上限从指令限幅变为**指令/涌现分层**（H6/H9）。

## 5 风险

1. **eta 结论方向依赖 H5 缺省**（最大学术风险）——缓解：WP5 敏感性带强制随所有 eta 结论发布，P4 标定后升级；
2. **涌现上限偏保守**（H9 为已验证下界）——饱和触发电压偏早属已知方向性偏差，敏感性两档对照入验收包；
3. **内核替换引入回归**——A3 门槛重新预登记把响应形态变化合法化，其余门槛数值不变，避免"调门槛凑结果"；
4. **E_pred 重建纪律**——名义图版本跑批前冻结入库，防止循环论证（Codex 独立复验重点核查项）；
5. **R2022b 堆崩溃环境限制**——沿用入库驱动有界重试纪律（rules v1.7），正式跑批期间工作树冻结；
6. **M3 独立复验排期**——不阻塞 WP1–WP6，仅 WP7/T2.4 后置。
