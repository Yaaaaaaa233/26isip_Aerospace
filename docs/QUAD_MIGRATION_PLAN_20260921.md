# 四旋翼迁移与油门-电压功率估计链：执行路线与验收方案 v1.0

日期：2026-09-21 ｜ 拟稿：叶安（ZCode 协助） ｜ 状态：**Proposed（待拍板 D1–D4 后入库执行）**

权威关系：本文件是阶段计划；阶段与放行的权威是 [`PROJECT_EXECUTION_ROADMAP.md`](PROJECT_EXECUTION_ROADMAP.md)；进度权威是 [`DEVELOPMENT_STATUS.md`](DEVELOPMENT_STATUS.md)；验收自动化规则遵循 [`ACCEPTANCE_AUTOMATION_RULES.md`](ACCEPTANCE_AUTOMATION_RULES.md)。

## 0. 背景与输入（2026-09-21）

- 老师约束（叶安转述）：**实机无法直接获得输出功率**；可观测 = 每电机油门（飞控下发的控制量）+ 电池电压（传感器直读）。现有算法的功率输入需适配该变化。
- 载具更换：四轴八旋翼（X8，小学期）→ **四轴四旋翼**；工作重心不在转速比优化（X8 eta 线成果随其冻结状态关闭，不迁移）。
- 老师要求在 Simulink 建四旋翼模型；具体参数后续提供，现阶段以既有台架（MN1005）与电池 v1 数据占位。
- 讨论结论（2026-09-21，本方案依据）：
  1. 慢/快分层原则下，算法保持"**标量功率 + v_ref**"接口抽象不变；油门+电压→功率 P̂ 的估计放**测量适配层**，不进算法接口面；
  2. 现有两条链现状：`models/plane`（P2）**不用油门**（PWM 是反推诊断量），`models/px4_x8/+x8phys` **油门正向**但功率系数代理级——迁移 = x8phys 的结构 + plane 链的台架标定，合到四旋翼；
  3. 核心风险 = 功率从"测量"变"估计"：误差从 0.2 s/1.2% 无偏噪声变为**有结构、有偏、与被学习信号（风/空速）相关**的模型失配。量化锚点：平台曲线谷底二次系数 k≈12 W/(m/s)²，估计器倾斜偏差 b₁≈1.3–1.4 %/m/s 即把拟合谷底推歪 0.5 m/s（代价 ≈0.35% 超额，与现有最优臂全部赢面同量级）。

## 3. 拍板项（需叶安确认后执行）

- **D1 估计器结构分级**：
  L0 = 静态映射 `P̂ = Σ P_bench(n̂ᵢ(pwmᵢ), V̂)`（无气速项、无动态——实机一张查表就能实现）；
  L1 = L0 + 气速修正（用算法侧地速 + 当前 ŵ 迭代喂回）；
  L2 = L1 + 电池动态。
  **推荐：L0 先行入 Q1/Q3；L1 仅当 Q1 实测临界倾斜 b₁* 不够用时启用**（L1 有 ŵ 反馈闭环，需额外稳定性论证）。
- **D2 新对象双轨制**：
  轨 A = MATLAB 降阶链（`plane.step` 骨架复用，4 电机单桨）——算法线日常实验，迭代快；
  轨 B = Simulink 四旋翼权威模型（x8phys 结构移植，油门正向）——老师要求 + M4/SITL 接口位；
  两轨以 M4' 对拍门绑定（准稳态曲线 ≤1.5%、就位时间比 ≤2×）。
  **推荐：双轨并行，轨 A 先行（约 1 周可跑通），轨 B 随后对拍收口。**
- **D3 算法输入电压归一化**（P̂ 除以当前电压下悬停功率估计 P̂_h(V̂)，消电压漂移共模）：按 Q1 场景 S4 数据拍板。
- **D4 任务编号与模块命名**：平台线 Q1 模块 `models/plane_quad`（暂名）；算法线 T3.9 模块 `modules/platform_link_39`（暂名）；Simulink 模型 `models/px4_x8/air_quad.slx` 或新目录 `models/quad/`（暂名）。可改名，登记表同步。

### Q1 X8 估计器敏感性批（2–3 天，**立即可跑，不依赖四旋翼**）
在现有 X8 P2 链上把测量链换成 L0 估计器，植物保留真值与全部物理层，量化估计误差容忍度：
- 估计器输入：植物诊断输出 `motor_pwm_us`（8 元）+ 当前端电压 V——即实机"指令侧 + 传感器侧"可观测量的仿真对应物；
- 估计器结构：静态台架映射（ pwm → n̂ → P_bench(n̂,V) ），**不含 H3 诱导项**（实机静态标定做不到的事）；
- 预注册场景矩阵：

| 场景 | 内容 | 档位 |
|---|---|---|
| S1 | 常数乘性偏差 | ±3%、±5% |
| S2 | 线性倾斜偏差 b₁ | +/−0.7、1.4、2.8 %/m/s |
| S3 | 结构性偏差 = 估计器关 H3 | 物理内置诱导偏差实测 |
| S4 | 电压/SOC 慢漂移 | 满电 → 90% 全窗 |
| S5 | 驻留违规（就位语义） | 指令后采样驻留 1/2/5 s |

- 指标：Δû\*、五臂超额 vs 开环（双口径）、windErr 漂移、赢面损耗 pp；
- 产出：**临界倾斜 b₁\***（吃光 4pp 赢面的倾斜量）、**可申报误差带草案**（→ D1/D3 输入）、S5 的最小驻留 t_dwell。
