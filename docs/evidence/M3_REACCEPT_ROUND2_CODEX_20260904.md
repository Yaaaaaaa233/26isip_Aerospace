## 3. 阻塞证据与修复边界

### 3.1 F2：评价器使用候选参考，周期末不等于中心；窗口也错一拍

源码：[m3_eval_arm.m](../../models/px4_x8/m3_eval_arm.m) 第 127–147 行把 `etaCand` 送入 [m3_eval_convergence.m](../../models/px4_x8/m3_eval_convergence.m)，后者直接取输入的周期末值计算 `abs(pe-1)`。完整周期的扰动均值可以为零，但**周期末的扰动值并不保证为零**，不能将这两种语义互换。

另一个同源问题是：M3 `convMask=searchE` 保留 t=240 样本，最后搜索段共 961 点；评价器从尾部截 960 点，实际使用 `[192.05,240]`。B2 显式使用 `[192,240)`，两者并不是文档声称的同窗。

独立反例保留真实 N5 其余日志，只构造末槽候选/实际比值作为离线评价输入：

```matlab
idx = logs.te2 >= 192;
t = logs.te2(idx);
center = ones(size(t));
center(t >= 197) = 1.009;
candidate = center + 0.02*sin(2*pi*0.25*(t-192)-pi/2);
logs.el(idx,1) = candidate;
logs.el(idx,2) = candidate;
% 由正式 m3_eval_arm 对该夹具评分；center 仅用于独立离线 oracle。
```

中心第一个完整周期末为 1，下一周期末为 1.009，向外回退 **0.009 > 0.005**，应拒收；候选在生产取样周期末叠加负扰动，反而看似接近 1。实际 `checker=1, converged=1, monotonic=1, ok=1`，均值 `1.008071875`，是假通过。将中心改为 `1.009 → 1`，真实中心趋近目标，checker 仍通过，但 `monotonic=0, ok=0`，是假拒收。相同相位的恒中心正控为 PASS，排除夹具普遍不合法造成旁因拒绝。

补充：转折放在 t=196 的原探针同样误放行，但此位置还受周期窗口错位影响；移至 t=197 用于独立确认候选扰动污染，属于定位同一既有判据，不新增性能要求。上述为明确构造的异常证据夹具，不声称真实内核产生了这种中心轨迹。

**正向边界**：按真实测量重放 eta 内核，五名义臂候选逐样本误差均 0；真实中心均满足原门槛。关闭需让正式路径取得可核验中心（例如离线重放并先与候选逐点对齐），统一 `[192,240)`，再对原始反例、相位正/负控及五名义臂回归。不能只改文档把“中心”改成“候选”便宣布修复。

### 3.2 F3：扰动场景仍会放过姿态越限

[m3_eval_arm.m](../../models/px4_x8/m3_eval_arm.m) 第 153–156 行对所有臂只硬判 yaw、范围、fallback 和位 1/2 时长；`hardMax==0` 仍仅在 `nominal` 分支执行。原合同 §6.3 对所有试验要求姿态限幅内。

在真实 D1 归档副本中，仅把 `logs.A(:,29)`（位 3，姿态越限）在 `[210,214)` 置 1，正式评价返回 **`hardMax=1, chk.pass=1, ok=1`**。这是一个故意不一致的离线故障夹具，应被安全合同拒收；不表示真实模型出现了姿态失稳。原始 `[210,214)` 位 1/sat 反例本轮返回 `hard12OK=0, ok=0`，证明该分支已修好，剩余缺口是其他合同必需安全量。

关闭需为扰动臂落实姿态门（使用原有标志/姿态限幅语义），保留原始饱和、NaN、停搜、v hold 漂移及合法监督恢复正控。不要为评价器漏检修改 ESC 内核。速度候选未落日志、eta 第 2 列是物理实际量等 V1 限制继续登记；本轮不要求为此直接改 `.slx`。
