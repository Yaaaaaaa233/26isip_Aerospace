## 1. 交付内容

- `+quad_sim/config.m / step.m / reset.m / ctrl.m / trim_run.m`：x8phys 结构（冻结只读移植）+ plane 台架标定的融合链：
  - **结构**（自 x8phys）：PWM→throttle→ω_target = throttle·KV_eff·V̂（固定点电压耦合 4 次迭代）→一阶电机滞后 τ=0.08 s→推力/力矩→NED/FRD 四元数刚体→逐轴废阻→电池链（V·I=P 恒等式）；
  - **标定**（自冻结源）：推力图 = MN1005 台架 T(n)（替代 ct·ω² 代理）；电功率图 = 分块 P(n;V)（替代 linear+cubic 代理）；H3 诱导节省同轨 A 式；KV_eff = ceiling_kn_rpm_per_V 使满油门 = n_ce(V)（与 P2/轨 A 的 PWM 派生式与 H9 同义）；
  - **ctrl.m**：v_ref→4×PWM 薄内环（"飞控模拟"）——传感器集 = 地速/姿态/角速度/电压（实机 FC 可观测量），H6 型前向通道 + 垂直阻尼 + 姿态 PD + 悬停线性化混控（pinv）+ 台架 T⁻¹ 反查；
  - **电气记账与轨 A 同口径**：机身废阻功计电功率（标量 |v_air|³，CdA=0.30）——x8phys 原结构只计桨+aux，若沿用将在速度域系统性偏低 33%，对拍不可比（发现过程见 §3）；
  - J² 前进比功率负载因子 = 声明级旋钮（`rotor_advance_power_gain`，默认 3.0 自 x8phys；**对拍模式置 0** 以隔离实现差 vs 声明物理差）。

## 3. 调试中发现并修复的结构问题（全部入档）

1. **垂直通道符号**：az_fb = +kvz·vz（NED 下正：vz>0 下降需抬推力制动）。初版反号 → 高度发散 → 终端下降流穿桨盘（轴向负载因子 1.09 特征）→ 高速功率虚高 41%；
2. **电气记账口径**：x8phys 原结构电功率不含机身废阻功；轨 A/P2 含。轨 B 初版沿用 x8phys 口径 → 高速端比轨 A 便宜 33%。修复 = 废阻功计电功率（标量口径与 A 一致），J² 项保持声明级附加；
3. 其余：config 空/struct 首参约定、H3 向量化、混控矩阵拼接（3×4）、测试输出捕获与匿名闭包陷阱。

- **P̂_L0 全程平坦（极差 0.94%）**：油门→转速→台架功率这条静态链在 2–10 m/s 看不到任何谷——**L0 盲性在轨 B 独立结构上复现**，与 Q1/S3 互证。D1（升 L1）结论加固；
- bias 驼峰结构：谷区 +19.9%（H3 缺失主导，与 Q1 X8 S3 的 +20% 量级一致）→ 高速翻负（J² 惩罚 + 废阻抬高真功率而 n̂ 几乎不动）；
- J² 项把真值谷底 5.65 → 5.00 m/s、Pmin +3.6%——四旋翼真值曲线比轨 A 更浅谷更高耗，**占位口径下的方向性参考**，Q4 正式批用真值链数值；
- **声明边界（重要）**：本复核只覆盖**功率侧** J 效应。**推力侧 n 效应**（真实螺旋桨前飞时同推力转速下降 → pwm 携带空速信息 → L0 可能不盲的唯一通路）不在 x8phys 结构内、也无台架数据（静态台架测不出）——需老师风洞/飞行数据（C2）或 Q3 实机 pwm-功率对拍。在此之前，"L0 盲"是当前两条结构链的一致结论，非最终实机结论。

## 5. t_dwell（Q1/S5 遗留 → 本批关闭）

电机 spool 一阶 τ=0.08 s（x8phys 声明级占位，实机电机待 C2）：4τ = **0.32 s**。加上姿态环（就位带宽内），接口文档"指令后驻留 ≥2 s"覆盖电机贡献余量充足——**Q1 的 t_dwell 草案定稿为 ≥2 s（以就位带为准）**；τ 换真机参数后按 4τ 复核。
