## 1. 交付物与设计声明（D1/L1）

- `+q39/est_l1.m`：L1 = L0 + 声明系数气速修正，修正结构与 Q1 离线分解逐项同型
  （`trim_curve.m`）：
  `P̂_L1 = P̂_L0(n̂(pwm),V̂) − dH3 + dH5 + dDrag + aux`，其中
  dH3 = 8·sav(动量理论诱导节省)、dH5 = 4·(bench−sav)·δ(共轴惩罚作用于扣 H3 后)、
  dDrag = 0.5·ρ·CdA·û³、aux = 常数辅助负载。悬停域修正退化为 +aux。
- **声明系数口径**：修正系数默认 = 配置自身标定值（声明上界档）；`decl` 覆盖参数
  支持降档敏感性（Q4 用），与 Q1 的 s1/s2 合成残差机制正交；未知覆盖字段拒绝。
- **估计空速 û̂ 的因果红线**：û̂ = |(测量地速 − 风测量)·切向|，只用测量面字段
  （全仓 `v_air = v_ground − wind` 减号约定），不读植物真值空速；结构门 +
  行为门（est_now 块文本禁 `air_velocity`）双保险。
  平台链 `wind_measured` 全量可见 → 本链 û̂ 无需 ŵ 迭代；实机传感器集下的
  ŵ 反馈闭环稳定性论证（D1 注记）显式留待实机阶段，不在本链声明范围。
- `+q39/make_platform_plant_l0.m`：`estMode='l1'` 分支——`q()` 返回与逐秒
  `powerMeas` 列 = 估计链（0.2s 时延 + 1.2% 噪声语义照搬 T1）；真值列
  （powerTrue / minPowerTrue 滑动电压）与基底逐位一致；s1/s2/s4/dwell 场景
  机制对 l1 照常生效（残差乘子沿用真值空速口径，与 Q1 各档可比）。
- `+q39/m7_metrics.m` + `m7_rows.m` + `run_q3_smoke.m`：M7 双口径记账层——
  同一幕、同一参照列（minPowerTrue），真值/估计两口径各记超额与 MOE，
  每臂展开 true/est/diff 三行（diff 行 = 双口径差，无列语义可核对）；
  known 臂按 3.8 修复语义仍为 oracle 上界，不入双口径对比。
