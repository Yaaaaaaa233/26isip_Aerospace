## 0. 一句话结论

**L0 纯静态查表（油门+电压→台架功率）在 P2 结构口径下不可直接部署**：谷底由 H3 前飞诱导项创造，静态映射曲线无谷，sweepcal 型全局拟合算法被拖到支撑下界（赢面 −11.65pp，灾难性）；purerl 型局部比较算法部分幸存但赢面磨损过半（5.80→2.74pp）。**曲线形状必须进估计器（至少 L1 档：气速修正项）**。在"估计器已抓住曲线形状、仅剩标定残差"的口径下（D1 的 L1 设计问题）：**临界倾斜 b₁\* = −2.6~−2.8 %/m/s**（sweepcal，负倾斜方向先破），purerl_off/on 在 ±2.8 %/m/s 全档未破；常数乘性偏差 ±5% 全档无害（≤0.05pp）；电压标定偏差 ±1% 只产生常数性平移（margin 零磨损，**D3 电压归一化不需要**）；固定驻留 ≤2 s 无损、5 s 因预算侵蚀（**t_dwell 实机值由 Q2 轨 B 电机动态定，接口先按 ≥2 s 申报**）。

## 4. 决策输入（D1/D3）

- **D1（估计器分级）**：L0 纯静态映射**不可作为部署口径**（P2 表述下 sweepcal 灾难性、purerl 磨损过半；即使按实机 n 效应的乐观解释，谷形状进入估计器也是必要非充分条件）。**推荐 L1 档（气速修正）为四旋翼默认设计目标**；L1 的气速信息来源（算法侧 û 反馈或实机 pwm 的 n 效应）在 Q2 轨 B 对拍后定。L1 残差容忍带见 §3 S1/S2。
- **D3（电压归一化）**：**不需要**。±1% 电压标定偏差在 L0 全链（反解+查表同污染）下只产生 ~±3% 常数性功率偏差，margin 磨损 0.01~0.23pp（§3 S4）；全窗 SOC 跌落亦无附加结构误差。
- **可申报误差带草案**：估计器残差若满足"常数偏差 ≤5% 且倾斜 |b₁|≤1.4 %/m/s"，五臂真值口径赢面磨损 ≤0.9pp（本测试台实测上界，与 M6 的 ≤1pp/臂 门自洽）；|b₁|≤2.8 时 purerl 臂 ≤1.9pp、sweepcal 臂负方向破线。→ **Q4/M6 放行带建议按"常数 ±5% + 倾斜 ≤1.4 %/m/s"申报**。
- **t_dwell（就位语义）**：P2 口径下固定驻留 ≤2 s 无损、5 s 因预算侵蚀明显；瞬态污染主导的驻留需求只在实机电机动态中出现 → 接口文档申报"驻留 ≥2 s 或以就位带为准"，Q2 轨 B 复测定稿（R4 缓解按此口径落地）。
- **win-rate 损耗参照（M6 基线）**：本批 L1 残差带内最坏磨损 0.9pp < M6 门 1pp；L0 口径（若 Q2 证实实机也无 n 效应）purerl_off 磨损 3.06pp 超 M6 门 → 直接进入"升 L1"分支，Q4 正式批不得在 L0 口径下跑。
