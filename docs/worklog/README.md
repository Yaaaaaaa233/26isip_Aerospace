本目录存放跨 agent、跨机器协作的**会话交接简报**：每篇记录一次工作会话的提炼结果，按时间追加。它与 `docs/DEVELOPMENT_STATUS.md` 分工明确——

- `docs/DEVELOPMENT_STATUS.md`：**单一事实来源**，始终反映仓库当前状态，随工作推进原地更新；
- 本目录：**追加式历史**，只增不改，供后续会话回溯"当时为什么这么做"。

新会话推荐顺序：读 `AGENTS.md` → 读 `DEVELOPMENT_STATUS.md` → 需要背景时回溯本目录。

## 约定

- 每次工作会话结束前新增一篇，文件名 `YYYY-MM-DD-主题.md`，如 `2026-08-31-m0a-powers-estimation.md`。
- 只写提炼后的要点，一篇控制在几十行内；agent 对话原文、原始终端输出不要提交进仓库。
- 若后续工作推翻或修订了某篇简报中的结论，在新简报中明确标注（"修订 2026-08-31 简报中的第 X 点"），不回头改旧简报。
