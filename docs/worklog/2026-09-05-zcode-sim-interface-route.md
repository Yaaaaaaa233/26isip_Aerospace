## 关键决策与理由

- Task 1 / Task 2 映射到既有路线工作包（ENV 收口、harness↔Plane 对接即汇合 R1/R2、M3 统一 Plane 复跑即 R4、统一 Harness 汇合），不另立内部阶段顺序，避免与 `PROJECT_EXECUTION_ROADMAP.md` 的阶段权威冲突。
- Percent 以 `E_pred`（算法预测最优能耗）为分母，区别于先验 `Emin = Pmin·T` 口径；当预测最优可达时两者近似相等，报告中并列给出。
- 风速参考 ≠ 风真值：开环 nominal_sched 可按风参考计算名义调度；闭环在线策略只可用风测量与历史数据（公平性与因果红线）。
- 接口文档落在 `docs/interfaces/`（阶段接口角色），只细化 `architecture/04_interface_dictionary.md` 的公共字段，不另立语义。
- 三步走中第①步为 Oracle 上界（不得写成在线策略成果）、第③步为默认在线口径（因果红线）；「曲线已知」指算法持有名义图 `P_nom`，运行对象始终是 `P_hidden`，两者偏差计入 Percent。
