## 4 Percent 与 T2 判据

1. **三步 Percent**：口径沿用 T1 冻结定义（Percent = 100×(E_actual−E_pred)/E_pred，E_pred 共用分母，≥20 种子，报告均值/最差/抖动与同种子配对差）；nominal_sched |Percent| 中位数参考带 ≤5%；
2. **E_pred 重建（拍板）**：proxy U 形退役为历史对照；E_pred 由冻结后的 P2 合成模型按 T1 流程重建（名义图沿计划调度 4-迭代固定点 rollout，含计划暂态），重建所用名义图版本在**跑批前随场景预登记入库**；T1/M3 历史能量数值与裕量不迁移、不横比；
3. **配对横评**：fixed / nominal_sched（及接入的 ESC 臂）同种子配对差报告；
4. **零硬违规**：`constraint_flags` 硬位（夹断持续、异常/缺失窗内策略外行为）零容忍；
5. **T2.4**：M3 统一 Plane 复跑——依赖 M3 独立复验通过 + P2 验收通过，未放行前不启动。
